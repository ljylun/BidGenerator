# 结语与附录

## 结语：财务分析是一副眼镜

九章走完了。现在你手里多了几样东西：

- 看报表的眼睛——知道三张表怎么串成一条活链
- 做体检的尺子——杜邦分析把 ROE 拆成三块
- 画路线图的工具——销售百分比法和情景分析
- 管增长的仪表盘——可持续增长率告诉你"能不能撑住"
- 选融资的指南针——债券、股票、风投、IPO 各有各的性格
- 定杠杆的秤——借钱的甜头和苦果，怎么平衡
- 算价值的公式——NPV 是最可靠的裁判
- 测风险的雷达——敏感性分析找到最脆弱的假设
- 估公司的透镜——DCF、可比公司、可比交易三种方法综合运用

这些工具不会自动给你正确答案。它们是一副眼镜——戴上之后，你能看得更清楚，但判断还得你自己做。

财务分析的最后一条铁律：**技术永远不能替代思考。** 定义问题、选择工具、解读结果、在不确定中做判断——这些是机器做不了的事。

一个笨人能学会的事，另一个笨人照样能。

## 附录一：术语小词典

| 术语 | 大白话 |
|------|--------|
| **资产** | 公司有什么——现金、库存、设备、别人欠的钱 |
| **负债** | 公司欠什么——银行贷款、供应商的账 |
| **股东权益** | 资产减负债——股东真正拥有的 |
| **收入** | 卖产品/服务赚到的钱 |
| **净收入（利润）** | 收入减去所有费用后剩下的 |
| **折旧** | 设备用久了变"旧"了，在账本上记录的价值减少 |
| **营运资本** | 流动资产减流动负债——日常经营需要的"垫付资金" |
| **自由现金流** | 公司赚到的、可以分配给所有投资者的现金 |
| **ROE** | 净资产收益率——股东每投一块钱赚回几毛 |
| **ROA** | 总资产回报率——每块钱资产赚回几毛 |
| **杜邦分析** | 把 ROE 拆成利润率 × 周转率 × 杠杆 |
| **可持续增长率** | 不靠外部融资，靠自己的利润最多能支撑多快的增长 |
| **财务杠杆** | 用别人的钱来赚钱——好的时候放大收益，差的时候放大亏损 |
| **WACC** | 加权平均资本成本——公司融资的"平均利率" |
| **NPV** | 净现值——项目未来现金流的现值减去初始投资 |
| **IRR** | 内部收益率——使 NPV = 0 的折现率 |
| **折现率** | "钱被绑住"的代价——未来的钱折算成今天的钱用的利率 |
| **β 系数** | 一只股票跟着大盘走的程度 |
| **CAPM** | 算股权成本的公式：r_e = r_f + β × (r_m - r_f) |
| **APV** | 调整现值——全股权价值 + 融资副作用（税盾） |
| **EV/收入倍数** | 企业价值除以收入——可比公司估值的常用倍数 |
| **控制权溢价** | 买下整家公司比买一股股票多付的钱 |
| **沉没成本** | 已经花出去、收不回来的钱——决策时不算 |
| **税盾** | 利息抵税带来的价值——借钱的一个好处 |

## 附录二：一页纸速查

### 第一部：看懂家底

```
三张表的关系：
  资产负债表（照片）→ 资产 = 负债 + 股东权益
  利润表（录像）→ 收入 - 费用 = 净收入
  现金流量表（流水账）→ 经营 + 投资 + 融资 = 现金变动

杜邦分析：
  ROE = 净利率 × 资产周转率 × 权益乘数
       (赚多少)   (转多快)     (借多少)
```

### 第二部：规划未来

```
外部融资需求 = 资产增加 - 自发负债增加 - 留存收益增加
             = 需要花的 - 自动来的 - 自己赚的

可持续增长率 SGR = ROE × 留存收益率
  → 实际增长 > SGR：需要外部融资
  → 实际增长 < SGR：有多余现金
```

### 第三部：融资决策

```
融资顺序：内部资金 → 债务 → 股权

杠杆的权衡：
  收益：税盾 + 放大 ROE
  成本：财务困境 + 代理成本

WACC = (E/V) × r_e + (D/V) × r_d × (1 - 税率)
```

### 第四部：投资决策

```
NPV > 0 → 投
NPV < 0 → 不投
IRR > 资本成本 → 投（但听 NPV 的）

风险分析三步：
  1. 敏感性分析 → 找最脆弱的假设
  2. 情景分析 → 乐观/基准/悲观
  3. 模拟 → NPV 的概率分布

估值三种方法：
  1. DCF → 未来现金流的现值
  2. 可比公司 → 类似公司卖什么价
  3. 可比交易 → 并购市场实际价格
```

## 附录五：贯穿概念回顾

全书用 Polaris Inc. 串起了所有概念：

- **第 1 章**：认识 Polaris 的报表——70 亿美元销售、46 亿资产、20 亿股东权益

- **第 5-6 章**：Polaris 怎么融资——负债权益比 1.68，杠杆中等偏高
- **第 7 章**：Polaris 的电动 ATV 项目——NPV 3 亿，值得投
- **第 8 章**：这个项目有什么风险——年现金流最敏感
- **第 9 章**：如果要买下 Polaris——用三种方法综合估值
