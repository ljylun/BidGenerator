# Keshav Three-Pass Reference Card

## Pass 1 (5–10 min): Bird's-Eye View
Read: title, abstract, intro, headings, conclusions, references
Output: Five Cs — Category, Context, Correctness, Contributions, Clarity

## Pass 2 (≤1 hour): Content Grasp
Read: full paper (skip proofs), examine all figures
Output: main thesis, methods, key figures, gaps, references to follow

## Pass 3 (1–5 hours): Deep Understanding
Method: Virtual re-implementation — recreate the work, then compare
Output: structural reconstruction, innovations, hidden assumptions, weaknesses, future directions

## Literature Survey (3-Step Loop)
1. Seed: 3–5 recent papers → Pass 1 → read Related Work → find survey
2. Identify: shared citations + repeated authors → key papers + top conferences
3. Scan: recent proceedings → Pass 1+2 on all → iterate until convergence

## Quality Signals to Watch
- Figures: axes labeled? error bars present? visuals match claims?
- Assumptions: stated vs. hidden?
- Baselines: are comparisons fair and complete?
- Citations: are key prior works cited?
- Writing: can gist be understood in one pass?
