# 🧠 Competitor Analysis Skill

## 🎯 功能
本技能用于对指定产品或行业进行竞品分析，包括：

- 竞品识别
- 产品对比
- 定价分析
- 渠道拆解
- 营销策略分析
- 用户人群分析
- SWOT分析
- 机会点挖掘

---

## 🚀 使用方式

输入示例：

分析对象：无糖气泡水
 目标市场：中国
 竞品数量：5

##  📊 输出结果

生成结构化报告，包括：

- 竞品列表
- 核心参数对比表
- 价格带分析
- 渠道结构
- 营销打法
- 用户画像
- SWOT
- 增长机会建议
