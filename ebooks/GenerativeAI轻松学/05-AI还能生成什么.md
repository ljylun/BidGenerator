# 05-AI还能生成什么

## 开篇除恐

前面四章，我们已经见识了AI的**文字**和**图片**生成能力。但AI的本事不止这些。

这一章我们快速浏览一下：AI还能写代码、编音乐、剪视频。你不需要深入学每一个，但你要知道**这些能力存在，以及什么时候该用**。

---

## 白话化：把术语扒光了看

### 代码生成

**大白话**：代码生成就是AI当"编程助手"，你描述需求，它写代码。

**原书说明**：代码生成不是让AI从零写整个应用，而是辅助开发者写函数、写模板、写 boilerplate code 。

### GitHub Copilot

**大白话**：Copilot就是你的"代码副驾驶"。你在IDE里写注释，它自动补全代码。

**经典案例**：OpenAI联合创始人Andrej Karpathy说，Copilot帮他写了约80%的代码。

**原书说明**：Copilot基于OpenAI Codex模型，支持几乎所有主流编程语言。

### 视频生成

**大白话**：视频生成就是AI当"导演"。你给它剧本，它拍出短视频。

**代表性模型**：
- Sora（OpenAI）：能生成最长1分钟的视频，角色和动作连贯
- Runway Gen-2：类似Sora的能力
- Pika：AI视频生成器，支持3D动画
- Stable Video Diffusion（Stability AI）：开源方案

**原书说明**：Sora在2024年初发布，标志着AI视频生成进入新阶段。

### 音乐生成

**大白话**：音乐生成就是AI当"作曲家"。你描述风格和情绪，它谱曲。

**代表性模型**：
- MusicLM（Google）
- MusicGen（Meta）

**原书说明**：音乐生成仍处于早期阶段，但进步迅速。通常生成30秒到几分钟的片段。

| 功能 | 对应AI能力 | 成熟度 |

## 例子贴身

### ☼ 热身：用AI写一段Python代码

**原书** 展示了用GPT-3.5生成"Hello World"的例子，包含调用OpenAI API并翻译成法语。

**自编** 更实际的例子：写一个**电商订单查询函数**。

**Prompt**：

> 写一个Python函数 `query_order_status(order_id)`，连接到模拟数据库，返回订单状态（待支付/已发货/已完成）。包含异常处理和日志记录。

**AI生成的代码**：

```python
import logging
from datetime import datetime

# 模拟数据库
mock_db = {
    "ORD123": {"status": "shipped", "updated_at": "2024-01-15"},
    "ORD456": {"status": "pending", "updated_at": "2024-01-16"},
}

def query_order_status(order_id):
    """查询订单状态"""
    logging.info(f"查询订单: {order_id}")
    
    if not order_id:
        raise ValueError("订单号不能为空")
    
    order = mock_db.get(order_id)
    if not order:
        raise ValueError(f"订单 {order_id} 不存在")
    
    return {
        "order_id": order_id,
        "status": order["status"],
        "updated_at": order["updated_at"]
    }

# 测试
try:
    result = query_order_status("ORD123")
    print(f"订单状态: {result['status']}, 更新时间: {result['updated_at']}")
except ValueError as e:
    print(f"错误: {e}")
```

**说明**：AI不只是写代码，还写了文档字符串、异常处理、日志记录。你可以直接拿来用，或根据实际数据库结构调整。

### ☼☼ 正经：给客服机器人加多媒体能力（贯穿例子·第5章）

**场景**：你的电商客服目前只能处理文字。现在你想让它：

1. **听懂用户的语音消息**（语音转文字）
2. **用语音回复用户**（文字转语音）
3. **看懂用户发的商品视频**（视频理解）

**原书** 提到，Whisper是OpenAI的语音识别模型，可以把音频转成文字。

**自编** 你设计了客服机器人的多媒体架构：

```
用户发语音消息
    ↓
Whisper API（语音转文字）
    ↓
客服LLM处理（理解问题 + 生成回答）
    ↓
TTS API（文字转语音）
    ↓
用户收到语音回复
```

**代码实现**：

```python
import openai

def voice_customer_service(audio_file_path):
    """语音客服流程"""
    # 1. 语音转文字
    with open(audio_file_path, "rb") as audio_file:
        transcript = openai.audio.speech.create(
            model="whisper-1",
            file=audio_file
        )
    
    user_question = transcript.text
    print(f"用户问: {user_question}")
    
    # 2. LLM处理
    answer = customer_service_qa(user_question)  # 复用第3章的函数
    
    # 3. 文字转语音
    speech_response = openai.audio.speech.create(
        model="tts-1",
        voice="alloy",
        input=answer
    )
    
    # 4. 保存语音回复
    speech_response.stream_to_file("reply.mp3")
    
    return "reply.mp3"

# 用户发了一条语音："我的订单什么时候到？"
# 客服自动回复一段语音，同时生成文字版本
```

**效果**：用户可以用语音问问题，客服用语音回答，体验更自然。

**原书** 还提到了视频生成的早期应用。虽然目前视频生成还不成熟，但在营销场景（自动生成产品演示视频）有潜在价值。

## 这一章要带走的东西

- AI不仅能写文字、画图片，还能写代码、编音乐、剪视频。
- 代码生成是"辅助编程"，不是"替代程序员"。
- GitHub Copilot是最流行的代码生成工具，基于Codex模型。
- 视频生成（Sora、Runway）和音乐生成（MusicLM、MusicGen）仍处于早期，但发展快。
- 语音识别（Whisper）和语音合成（TTS）已经成熟，可集成到客服系统。
- 我们的客服机器人升级了：现在能听懂语音、用语音回复。
