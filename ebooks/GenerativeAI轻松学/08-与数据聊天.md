## 白话化：把术语扒光了看

### 数据 grounding

**大白话**：Data grounding就是**把AI和你的数据"连"起来**。

没有grounding的AI：知识截止到训练日期，不知道你的业务。
Grounding之后的AI：能访问你的数据库、文档、API，回答基于你的真实数据。

**原书说明**：Grounding通过RAG或其他方式，将LLM与外部信息源连接。

### 混合搜索（Hybrid Search）

**大白话**：混合搜索就是**关键词搜索 + 语义搜索**的组合拳。

- 关键词搜索：你搜"退货政策"，精确匹配含这四个字的文档
- 语义搜索：你搜"怎么退钱"，找到含"退款流程"的文档

混合搜索 = 两者都做，然后把结果合并排序，取最好的。

**原书说明**：Azure AI Search等支持混合搜索，结合全文检索和向量检索的优势。

### 语义排序（Semantic Ranking）

**大白话**：语义排序就是**让搜索结果更"懂你"**。

传统搜索按关键词匹配度排序。
语义排序理解查询的真实意图，把最相关的结果排前面。

**原书说明**：语义排序使用LLM对检索结果重新排序，提高相关性。

### 对话管理

**大白话**：对话管理就是**记住上下文**。

你和AI聊了3句，第4句提到"它"，AI要记得"它"指代什么。

**原书说明**：对话管理维护多轮对话的历史，确保AI理解上下文。

## 直觉先行：用"贴标签找东西"理解RAG流程

想象你在一个**超级图书馆**找书：

1. **你说**："我要找关于退货的书。"
2. **图书管理员**（Retriever）：
   - 先理解你的问题：你问的是"退货"
   - 在图书馆里找所有相关书籍
   - 不直接给你整本书，而是**撕下最相关的3页**
3. **你**（Generator/LLM）：
   - 拿到这3页内容
   - 结合你的问题，组织语言回答
   - 说："根据《退货手册》第12页..."

**RAG系统做的是同样的事**，只不过：
- 图书馆 = 向量数据库
- 图书管理员 = 检索算法
- 撕书页 = Chunking
- 你 = LLM

### ☼ 热身：用Redis做向量搜索

**原书** 展示了用Redis作为向量数据库的RAG实现。

**自编** 简化版，用Redis Stack：

```python
import redis
from openai import OpenAI
import numpy as np

# 连接Redis
r = redis.Redis(host='localhost', port=6379, decode_responses=True)

# 1. 准备知识库
docs = [
    "退货政策：15天无理由退货，需保留原包装。",
    "运费规则：满99免运费，不满收10元。",
    "VIP权益：9折优惠、优先发货、专属客服。"
]

# 2. 生成embedding并存入Redis
client = OpenAI()
for i, doc in enumerate(docs):
    emb = client.embeddings.create(model="text-embedding-3-small", input=doc)
    vector = emb.data[0].embedding
    r.hset(f"doc:{i}", mapping={
        "content": doc,
        "vector": np.array(vector).tobytes()
    })

# 3. 检索
def search_redis(query, top_k=1):
    query_emb = client.embeddings.create(model="text-embedding-3-small", input=query)
    query_vector = np.array(query_emb.data[0].embedding)
    
    # 使用Redis向量搜索
    results = r.ft("docs_idx").search(
        f"*=>[KNN {top_k} @vector $vec AS dist]",
        query_params={"vec": query_vector.tobytes()}
    )
    return [doc for doc in results.docs]

# 4. 生成回答
def rag_qa(question):
    context = "\n".join([d.content for d in search_redis(question)])
    response = client.chat.completions.create(
        model="gpt-3.5-turbo",
        messages=[
            {"role": "system", "content": f"根据以下资料回答：\n{context}"},
            {"role": "user", "content": question}
        ]
    )
    return response.choices[0].message.content
```

```python
# 对话历史存在Redis
def get_conversation_history(user_id):
    return r.lrange(f"chat:{user_id}", 0, -1)

def add_to_history(user_id, role, content):
    r.rpush(f"chat:{user_id}", f"{role}:{content}")
```
