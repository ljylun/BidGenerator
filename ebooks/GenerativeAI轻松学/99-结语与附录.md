# 99-结语与附录

## 结语

恭喜你读完了整本书。

从第1章的"生成式AI是什么"，到第13章的"怎么负责任地用它"，你走完了从入门到实战的完整路径。

**你已经不是AI小白了**。你知道：
- AI的本质是"预测下一个词"
- 怎么调API让它干活
- 怎么用prompt让它更听话
- 怎么用RAG让它查资料
- 怎么微调让它有性格
- 怎么搭成完整应用
- 怎么部署上线
- 怎么评估效果
- 怎么规避风险

**最重要的三句话**：

1. **AI不是魔法，是工具**。用好它靠的是你对问题的理解，不是对术语的背诵。
2. **先跑起来，再优化**。不要等完美方案，先用最简单的API做出Demo，再逐步迭代。
3. **人永远是第一责任人**。AI可以辅助决策，但最终责任在人。

**就这样，去 build 吧。**

## 一页纸速查

### 快速选模型

| 场景 | 推荐模型 | 原因 |
|------|----------|------|
| 简单问答、客服 | GPT-3.5 Turbo | 成本低、速度快 |
| 复杂推理、代码生成 | GPT-4 | 能力强 |
| 高并发、低成本 | 开源小模型（Llama 2 7B） | 可自托管 |
| 图片理解 | GPT-4V | 多模态 |
| 图片生成 | Stable Diffusion / DALL-E 3 | 质量高 |

### 快速优化Prompt

| 问题 | 解法 |
|------|------|
| 回答太笼统 | 加更多上下文和细节 |
| 回答不准确 | 用few-shot提供示例 |
| 回答不一致 | 调低temperature到0.3 |
| 回答太长 | 限制max_tokens |
| 回答跑题 | 用system message设定边界 |
| 需要推理 | 用Chain of Thought |

## 练法/用法建议

### 给初学者的建议

1. **先跑通Demo**：用OpenAI API做一个简单的问答机器人，30分钟就能跑起来。
2. **再优化Prompt**：用第6章的技巧，让回答更准确。
3. **再接知识库**：用第7章的RAG，让AI能回答专业问题。
4. **最后考虑微调**：只有当RAG和Prompt优化不够时，才考虑微调。

### 给进阶者的建议

1. **建立评估 pipeline**：第12章的评估体系，持续监控质量。
2. **关注成本**：用缓存、模型路由、小模型分类等手段降低成本。
3. **重视安全**：第13章的伦理和防护，从一开始就建好。
4. **保持学习**：这个领域变化快，关注arXiv、Hugging Face、OpenAI Blog。

### 企业落地路线图

```
Phase 1（1-2周）：PoC
- 选一个具体场景（如客服）
- 用现成API做Demo
- 验证价值

Phase 2（2-4周）：MVP
- 接入企业知识库（RAG）
- 优化Prompt
- 小范围试用

Phase 3（1-2月）：生产化
- 完整架构设计（第10章）
- 部署上线（第11章）
- 建立评估体系（第12章）

Phase 4（持续）：优化
- 收集用户反馈
- 微调模型（第9章）
- 迭代优化
```
