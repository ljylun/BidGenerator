# 04-图像生成

## 开篇除恐

上一章我们学会了"让AI写文字"。这一章我们让它**画画**。

你可能会想：AI画画是不是瞎画？是不是随机拼贴像素？

不是。

AI画画的过程，其实很像**一个画家在黑暗房间里慢慢显影一张照片**。它先从一团噪声开始，一点点"擦"出图像。听起来很玄，但原理简单得让你意外。

---

## 白话化：把术语扒光了看

### 视觉模型

**大白话**：视觉模型就是AI的"眼睛"和"手"——既能看懂图片，又能生成图片。

### 扩散模型（Diffusion Model）

**大白话**：扩散模型是当前最流行的AI画画技术。它的工作原理是：

1. 先找一张图片，慢慢加噪声，直到变成一团乱麻（这叫前向扩散）
2. 然后训练AI，让它学会**从噪声中恢复出原图**（这叫反向扩散）
3. 生成时，AI从纯噪声开始，一步步"去噪"，最终得到一张清晰的图

**类比**：就像你在雾里看风景——AI先往风景里加雾（训练），然后学会在雾里看清风景（生成）。

**原书说明**：Stable Diffusion、DALL-E 3、Midjourney都基于扩散模型或其变体。

### 变分自编码器（VAE）

**大白话**：VAE是一个"图片压缩+解压"工具。它把图片压缩成 latent space （潜空间）里的向量，再解压回来。

**好处**：在潜空间里操作图片更高效，就像在低分辨率草稿上作画，比直接在4K画布上画快多了。

**原书说明**：VAE是扩散模型的重要组成部分，用于编码和解码图像。

### 生成对抗网络（GAN）

**大白话**：GAN是"两个骗子互相较劲"。

- **生成器**：假装画真画
- **判别器**：假装能鉴别真伪

两者互相博弈，最终生成器画出来的画，判别器都分不清真假。

**原书说明**：GAN在扩散模型流行之前是主流，现在仍用于特定场景。

### Vision Transformer（ViT）

**大白话**：ViT就是把处理文字的Transformer**移植到图片上**。

原本Transformer处理文字token，现在把图片切成小块（patch），每个patch当一个token，用同样的机制处理。

**原书说明**：ViT让模型能同时理解文字和图像，是多模态模型的基础。

### 多模态模型

**大白话**：多模态模型就是**既看得懂文字，又画得了图**的模型。

比如GPT-4V（GPT-4 with Vision），你给它一张照片，它能描述照片内容；你给它文字描述，它能理解并生成相应内容。

**原书说明**：多模态模型是当前研究热点，能处理文本、图像、音频等多种输入输出。

## 直觉先行：用"去噪"理解Diffusion

想象你在一个完全黑暗的房间里，墙上挂着一幅画，但你什么都看不见。

现在有人打开了一盏微弱的灯（**第一步去噪**），你隐约看到画上有蓝色。
灯再亮一点（**第二步去噪**），你看出那是一片海。
灯继续亮（**第三步去噪**），你看到海边有个人。
最后灯全亮（**最终去噪**），你看清了整幅画：一个女孩站在海边看日落。

**Diffusion模型做的就是这件事**：

1. 训练阶段：拿真实图片，逐步加噪声，直到变成纯噪声。同时训练AI学会逆转这个过程。
2. 生成阶段：从纯噪声开始，AI一步步"去噪"，最终生成清晰图片。

**核心思想**：AI不是"一笔画成"，而是"从混沌中慢慢理出秩序"。

## 例子贴身

### ☼ 热身：用Python调用Stable Diffusion

**自编** 安装依赖：

```bash
pip install requests
```

写代码：

```python
import os
import requests

api_key = os.getenv("STABILITY_API_KEY")
response = requests.post(
    "https://api.stability.ai/v1/generation/stable-diffusion-xl-1024-v1-0/text-to-image",
    headers={
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json",
    },
    json={
        "text_prompts": [
            {
                "text": "一只戴着眼镜的柴犬，坐在书桌前敲代码，屏幕上显示Python代码，赛博朋克风格",
                "weight": 1
            }
        ],
        "cfg_scale": 7,
        "height": 1024,
        "width": 1024,
        "samples": 1,
        "steps": 30,
    },
)

# 保存图片
with open("coding_shiba.png", "wb") as f:
    f.write(response.content)
```

运行后，你会得到一张**1024x1024**的图片，内容就是你描述的那只编程柴犬。

### ☼☼ 正经：给客服机器人加图片识别能力（贯穿例子·第4章）

**场景**：你的电商客服机器人目前只能处理文字。现在用户经常发图片问："这个衣服有没有红色？""这个鞋子会不会磨脚？"

**原书** 展示了DALL-E 3生成图片的例子，以及Stable Diffusion的API调用。

**自编** 你决定用多模态模型（如GPT-4V）让客服能**看懂用户发的图片**：

```python
def customer_service_with_image(image_url, question):
    """支持图片的客服问答"""
    response = client.chat.completions.create(
        model="gpt-4-vision-preview",
        temperature=0.3,
        messages=[
            {
                "role": "user",
                "content": [
                    {"type": "text", "text": f"你是XX电商客服。用户发了一张图片并提问：{question}。请礼貌、准确地回答。"},
                    {"type": "image_url", "image_url": {"url": image_url}}
                ]
            }
        ]
    )
    return response.choices[0].message.content

# 用户发了一张衣服图片
print(customer_service_with_image(
    "https://example.com/red-dress.jpg",
    "这件衣服有红色吗？适合什么场合穿？"
))
```

**输出示例**：

> "您好！图片中是一件红色连衣裙，颜色鲜艳，适合参加婚礼、晚宴等正式场合。这款裙子目前有红色、蓝色和黑色三种颜色可选。如有其他问题，欢迎继续咨询！"

**效果**：客服机器人从"只能打字"升级到"能看懂图片"，用户体验大幅提升。

**原书** 还提到了图像编辑功能，如inpainting（局部重绘）、outpainting（扩展画布）、upscaling（放大图片）。这些在企业设计、营销素材制作中非常有用。

## 这一章要带走的东西

- AI画画不是瞎画，是"从噪声中慢慢去噪"。
- 扩散模型（Diffusion）是当前主流技术，原理是"先加噪，再学去噪"。
- VAE是图片压缩工具，GAN是"骗子与鉴别器"的游戏，ViT是处理图片的Transformer。
- 多模态模型能同时理解文字和图像。
- Prompt要详细描述主体、风格、情绪、光线、视角。
- AI画不好手、脸、文字，需要后期处理。
- 我们的客服机器人升级了：现在能看懂用户发的图片。
