# 00-目录与体例.md

## 书名

**生成式AI轻松学**

副标题：从怕到会，像学算术一样学生成式AI

---

## 四部式结构

| 部分 | 主题 | 定位 |
|------|------|------|
| 第一部 别怕，这没那么玄 | 生成式AI到底是什么 | 除恐、建立直觉 |
| 第二部 动手之前先搞懂规矩 | 核心概念与模型 | 术语脱西装、规则讲透 |
| 第三部 真刀真枪干起来 | 应用开发实战 | 例子贴身、拿来就用 |
| 第四部 上了规模怎么办 | 部署、评估与伦理 | 工程化、避坑指南 |

---

## 每章除恐主旨

| 章 | 原书对应 | 除恐主旨 |
|----|----------|----------|
| 01 | 第1章 Introduction | "生成式AI"四个字听起来吓人，其实就像教小孩画画——给个主题，让它自己发挥 |
| 02 | 第2章 LLMs | 大语言模型不是魔法，只是一个"下一个词预测器" |
| 03 | 第3章 API | 调API就像点外卖，填个表单就能让AI干活 |
| 04 | 第4章 图像生成 | AI画画不是瞎画，是"先懂画，再生成画" |
| 05 | 第5章 其他生成 | AI不仅能写能画，还能写代码、编音乐、剪视频 |
| 06 | 第6章 Prompt Engineering | 跟AI说话不需要玄学，有章法可循 |
| 07 | 第7章 RAG | 让AI"查资料再回答"不是什么黑科技，就是教它翻书 |
| 08 | 第8章 与数据聊天 | 用你自己的数据训练AI，不需要从零开始 |
| 09 | 第9章 微调 | 微调不是重造模型，是给通用模型"开小灶" |
| 10 | 第10章 架构 | 生成式AI应用不是堆模型，是搭积木 |
| 11 | 第11章 部署 | 上线不是结束，是另一场考试的开始 |
| 12 | 第12章 评估 | AI答得好不好，不是凭感觉，是测出来的 |
| 13 | 第13章 伦理 | 用AI不是没规矩，而是规矩比技术更重要 |

## 贯穿全书的例子

用「企业智能客服」作为主线例子，从第1章一直搭到第13章，每章加一点新功能：
- 第1章：想法萌芽
- 第2章：选模型
- 第3章：调API实现基础问答
- 第4章：加图片识别能力
- 第6章：优化提示词让回答更准
- 第7章：接入企业知识库
- 第9章：用微调让客服有"性格"
- 第10章：搭成完整应用架构
- 第11章：部署上线
- 第12章：做评估看效果
- 第13章：考虑伦理与合规

## 说明

本书仿 Silvanus Thompson《Calculus Made Easy》(1910) 风格编写。
目标：让怕术语、怕代码、怕"AI太玄学"的读者，逐章建立真实可用的知识。
每章严格走「开篇除恐 → 白话化 → 直觉先行 → 例子贴身 → 收尾」五段式。
