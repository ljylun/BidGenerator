## 白话化：把术语扒光了看

### 生成式AI应用栈（GenAI App Stack）

**大白话**：GenAI App Stack就是**一套积木的说明书**，告诉你哪些积木块该放在哪一层。

**原书说明**：GenAI App Stack是新兴的参考架构，包括数据层、模型层、编排层、应用层等。

### 编排层（Orchestration Layer）

**大白话**：编排层就是**总指挥**，协调各个组件协同工作。

它负责：
- 接收用户请求
- 决定调用哪个模型
- 管理上下文
- 调用外部工具
- 返回最终结果

**原书说明**：Orchestration frameworks如LangChain、LlamaIndex、Semantic Kernel简化了复杂AI工作流的开发。

### 工具使用（Tool Use）

**大白话**：Tool Use就是**让AI能调用外部工具**。

比如AI需要查天气，它不会自己上网查，而是调用一个天气API。

**原书说明**：Function calling让LLM能够调用外部函数和API，扩展能力边界。

### 护栏（Guardrails）

**大白话**：Guardrails就是**安全护栏**，防止AI输出有害内容或执行危险操作。

**原书说明**：Guardrails过滤不当内容，确保AI输出符合企业政策。

### 模型集成（Model Ensemble）

**大白话**：Model Ensemble就是**多个模型分工合作**。

比如：
- 小模型（Phi-2）负责分类：判断用户问的是不是关于狗的问题
- 大模型（GPT-4）负责生成：只有关于狗的问题才调用GPT-4生成详细回答

**好处**：省钱、提速、更灵活。

**原书说明**：Model ensemble结合不同模型的优势，优化成本和性能。

## 例子贴身

### ☼ 热身：用LangChain搭简单链

**原书** 展示了LangChain的基本用法，包括chains、agents、memory。

**自编** 用LangChain实现一个简单的客服链：

```python
from langchain_openai import ChatOpenAI
from langchain.chains import RetrievalQA
from langchain_community.vectorstores import FAISS
from langchain_openai import OpenAIEmbeddings

# 1. 加载向量数据库
embeddings = OpenAIEmbeddings()
vectorstore = FAISS.load_local("customer_service_index", embeddings)
retriever = vectorstore.as_retriever(search_kwargs={"k": 3})

# 2. 创建LLM
llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0.3)

# 3. 创建检索链
qa_chain = RetrievalQA.from_chain_type(
    llm=llm,
    chain_type="stuff",
    retriever=retriever,
    return_source_documents=True
)

# 4. 提问
result = qa_chain.invoke({"query": "怎么退货？"})
print(result["result"])
print("来源：", [doc.metadata["source"] for doc in result["source_documents"]])
```

**关键组件选型**：

| 组件 | 选型 | 原因 |
|------|------|------|
| API Gateway | Nginx / Azure API Management | 成熟、可扩展 |
| 编排框架 | LangChain | 生态丰富、文档全 |
| 向量数据库 | Pinecone / Azure AI Search | 托管服务、免运维 |
| 缓存 | Redis | 速度快、支持向量 |
| 模型路由 | 自研 | 成本优化 |
| Guardrails | NeMo Guardrails | 开源、可定制 |

**部署架构**：

```

- 多可用区部署，保证高可用

- 监控：Application Insights + Prometheus + Grafana
```

**效果**：系统可以支持**1000并发用户**，平均响应时间<2秒，可用性99.9%。

## 这一章要带走的东西

- GenAI App Stack是搭积木的说明书，不是单一技术。
- 编排层（Orchestration）是总指挥，LangChain、LlamaIndex是常用工具。
- 数据层（Grounding）存储知识库，向量数据库是核心。
- 模型层（Model）包括基础模型、微调模型、小模型。
- 工具层（Tool Use）让AI能调用外部API。
- Guardrails是安全护栏，防止AI输出有害内容。
- Model Ensemble用多个模型分工，优化成本和性能。
- 我们的客服机器人升级成了完整的企业级应用。
