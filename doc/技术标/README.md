## 使用说明

1. **独立审核**：每个章节可独立审核和修改
2. **并行编写**：不同章节可同时由不同人员编写
3. **合并生成**：编写完成后合并为完整版
4. **评分对照**：第十一章提供评分项响应索引，方便自查
