## 通用技术栈

| 层级 | 技术选型 |
|------|----------|
| **AI 模型** | 通义千问 VL 系列（qwen3-vl-flash/plus）、豆包 API |
| **NLP** | 通义千问、BERT |
| **ASR/TTS** | 火山引擎 |
| **数据存储** | MySQL、Redis、时序数据库（TDengine）、向量数据库（Milvus） |
| **消息队列** | RocketMQ |
| **前端** | 钉钉小程序、H5、管理后台 |
| **监控** | Prometheus + Grafana |
| **调度** | XXL-Job |
| **对象存储** | 阿里云 OSS |

## 注意事项

1. **数据安全**：所有涉及用户数据的场景需通过安全评审
2. **合规要求**：AI 生成内容需标注，遵守各平台规范
3. **人工兜底**：所有 AI 场景均需保留人工介入通道
4. **持续优化**：建立反馈闭环，持续提升模型效果
5. **成本控制**：设置 API 调用预算预警，实施请求过滤和缓存策略
6. **版本管理**：所有 PRD 文档遵循版本控制，变更需记录
