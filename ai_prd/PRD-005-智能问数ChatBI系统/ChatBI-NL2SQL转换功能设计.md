## 一、功能角色矩阵说明

### 1.1 功能描述

- **功能名称：** NL2SQL 转换
- **所属模块：** 智能问数主流程
- **功能描述：** 接收用户自然语言问题，结合数据库 Schema 和业务指标字典，通过 NL2SQL 模型将自然语言转换为可执行的 SQL 语句。

### 1.2 角色权限总览

| 角色      | 功能权限                        | 数据权限   |
| ------- | --------------------------- | ------ |
| 业务运营 | 无直接访问，作为主流程内部组件        | 无       |
| 管理层 | 无直接访问，作为主流程内部组件        | 无       |
| 数据分析师 | 查看转换结果、管理Prompt模板、查看准确率统计 | 全量数据   |
| 系统管理员 | 全部配置管理                    | 全量数据   |

### 1.3 功能角色矩阵

| 功能点  | 业务运营 | 管理层 | 数据分析师 | 系统管理员 |
| ---- | :-----: | :-----: | :-----: | :-----: |
| NL2SQL转换执行 |    否    |    否    |    否（自动触发）    |    否（自动触发）    |
| 查看转换结果 |    否    |    否    |    是    |    是    |
| 管理Prompt模板 |    否    |    否    |    是    |    是    |
| 查看准确率统计 |    否    |    否    |    是    |    是    |

## 三、状态流转与流程图

### 3.1 业务流程图

```mermaid
flowchart TD
    A[接收自然语言问题] --> B[输入预处理]
    B --> C[意图识别]
    C --> D{意图是否明确}
    D -->|否| E[返回澄清提示]
    D -->|是| F[指标匹配]
    F --> G[维度匹配]
    G --> H[过滤条件提取]
    H --> I[Schema映射]
    I --> J[生成SQL草稿]
    J --> K[SQL语法校验]
    K --> L{语法校验通过}
    L -->|否| M[SQL修正]
    M --> K
    L -->|是| N[安全检查]
    N --> O{安全检查通过}
    O -->|否| P[返回安全拦截提示]
    O -->|是| Q[输出最终SQL]
    Q --> R[输出指标解释]
    R --> S[输出维度信息]
    S --> T[输出过滤条件]
```

### 3.2 状态流转图

```mermaid
stateDiagram-v2
    [*] --> 待处理: 接收自然语言问题
    待处理 --> 意图识别中: 开始解析
    意图识别中 --> 意图明确: 成功识别查询意图
    意图识别中 --> 意图模糊: 无法识别查询意图
    意图模糊 --> [*]: 返回澄清提示
    意图明确 --> 指标匹配中: 匹配业务指标
    指标匹配中 --> 指标匹配成功: 找到对应指标
    指标匹配中 --> 指标未找到: 无匹配指标
    指标未找到 --> [*]: 返回指标不存在提示
    指标匹配成功 --> SQL生成中: 生成SQL草稿
    SQL生成中 --> 语法校验中: 提交语法校验
    语法校验中 --> 校验通过: 语法正确
    语法校验中 --> 校验失败: 语法错误
    校验失败 --> SQL生成中: 自动修正
    校验通过 --> 安全检查中: 提交安全检查
    安全检查中 --> 安全通过: 检查通过
    安全检查中 --> 安全拦截: 检测到风险
    安全拦截 --> [*]: 返回安全拦截提示
    安全通过 --> [*]: 输出SQL结果
```
