# 模块十一：系统管理与配置（M11）

> **优先级：P0**  
> **模块定位：** GEO 系统的"基座层"，负责账号权限、系统配置和日志审计，为整个系统提供基础支撑和安全保障。

---

## 17.1 功能清单

| 编号 | 功能名称 | 优先级 | 说明 |
|------|----------|--------|------|

| M11-F02 | 角色权限管理 | P0 | 角色定义、权限分配、角色-用户绑定，基于 RBAC+ABAC 模型 |

## 17.3 交互说明

| 交互项 | 触发条件 | 交互行为 | 备注 |
|--------|----------|----------|------|
| 账号 CRUD | 用户点击新建/编辑/删除账号 | 新建和编辑弹出表单弹窗；删除需二次确认（输入用户名确认）；支持批量导入（Excel 模板） | 删除为逻辑删除，30 天内可恢复 |
| 角色配置 | 用户修改角色权限配置 | 权限变更实时预览影响的用户数量；保存前展示变更对比确认 | 关键角色（管理员）变更需二次验证 |
| 组织配置 | 用户调整组织架构树 | 拖拽调整组织层级和顺序；支持组织合并、拆分、迁移 | 组织删除需先转移下属用户 |
| 日志查询 | 用户查询操作日志 | 支持多条件组合筛选（时间、用户、操作类型、模块）；结果支持导出为 Excel | 日志保留策略：在线 6 个月，归档 2 年 |
| 系统配置 | 用户修改系统参数 | 配置变更即时生效，无需重启；关键配置变更需管理员二次确认；记录配置变更历史 | 支持配置回滚到任意历史版本 |
| 密码策略 | 用户设置/重置密码 | 密码强度实时提示；支持强制密码过期策略；重置密码发送安全链接 | 密码需包含大小写字母+数字+特殊字符，≥8 位 |
| 登录控制 | 管理员配置登录策略 | 支持 IP 白名单、登录时间限制、并发会话控制、异常登录检测 | 异常登录触发邮件/短信告警 |
| 数据备份 | 用户触发手动备份 | 显示备份进度条；备份完成后提供下载链接；自动备份在凌晨 2:00 执行 | 备份文件加密存储，保留 30 天 |
| API 密钥 | 用户生成/管理 API 密钥 | 支持创建多个 API 密钥，每个可独立设置权限和有效期；支持密钥轮换 | 密钥仅显示一次，关闭后不可再查看 |
| 消息推送 | 管理员发送系统公告 | 支持按角色/组织/个人定向推送；支持定时发送；支持已读/未读状态追踪 | 紧急公告支持强制弹窗提醒 |

## 17.4 错误处理

| 错误场景 | 错误码 | 处理策略 | 用户提示 |
|----------|--------|----------|----------|
| 账号操作失败 | M11-E01 | 记录详细错误日志，回滚已执行的操作；提供重试按钮 | "账号操作失败：[具体原因]，请重试" |
| 权限配置错误 | M11-E02 | 配置变更前校验权限完整性；冲突时阻止保存并提示 | "权限配置存在冲突：[具体描述]，请修正后保存" |
| 配置变更失败 | M11-E03 | 自动回滚到上一个有效版本；记录变更失败原因 | "配置变更失败，已自动回滚到上一版本" |
| 日志查询超时 | M11-E04 | 超过 15 秒自动切换为异步查询，完成后通知用户 | "查询量较大，已转为异步处理，完成后将通知您" |
| 密码不符合策略 | M11-E05 | 实时校验并提示具体不符合项 | "密码不符合要求：[具体原因]" |
| 组织层级过深 | M11-E06 | 限制组织层级最多 10 级 | "组织架构层级不能超过 10 级" |
| API 密钥过期 | M11-E07 | 过期前 7 天发送提醒；过期后自动禁用 | "API 密钥已过期，请重新生成" |
| 备份失败 | M11-E08 | 自动重试 2 次；连续失败发送告警通知管理员 | "数据备份失败，已通知系统管理员处理" |
| 恢复失败 | M11-E09 | 恢复前自动创建当前状态快照；恢复失败可从快照还原 | "数据恢复失败，已保留当前系统快照" |
| 并发编辑冲突 | M11-E10 | 乐观锁机制，后保存者提示冲突并提供合并选项 | "该配置已被其他用户修改，请刷新后重试" |

### 17.5.2 RBAC+ABAC 权限模型详细设计

```
┌─────────────────────────────────────────────────────────────┐
│                    RBAC + ABAC 混合权限模型                   │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  RBAC 层（角色基础访问控制）                           │   │
│  │                                                     │   │
│  │  用户 ──绑定──▶ 角色 ──绑定──▶ 权限集合               │   │
│  │                                                     │   │
│  │  权限 = 资源 + 操作                                  │   │
│  │  例：dashboard:view, report:export, user:edit        │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  ABAC 层（属性基础访问控制）                           │   │
│  │                                                     │   │
│  │  策略 = 主体属性 + 资源属性 + 环境属性 + 操作          │   │
│  │                                                     │   │
│  │  主体属性：用户部门、职级、角色                        │   │
│  │  资源属性：数据归属部门、数据密级                      │   │
│  │  环境属性：访问时间、IP 地址、设备类型                 │   │
│  │                                                     │   │
│  │  示例策略：                                          │   │
│  │  "部门经理可查看本部门数据，仅工作时间从内网访问"       │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  权限判定流程                                        │   │
│  │                                                     │   │
│  │  1. RBAC 检查：用户角色是否拥有资源+操作权限？         │   │
│  │     └─ 否 → 拒绝                                    │   │
│  │     └─ 是 → 继续                                    │   │
│  │  2. ABAC 检查：是否满足数据范围策略？                  │   │
│  │     └─ 否 → 拒绝（或降级为只读）                     │   │
│  │     └─ 是 → 继续                                    │   │
│  │  3. 环境检查：是否满足环境约束？                       │   │
│  │     └─ 否 → 拒绝 + 告警                              │   │
│  │     └─ 是 → 允许访问                                 │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

### 17.5.7 备份恢复策略

| 备份类型 | 频率 | 保留周期 | 存储位置 | 说明 |
|----------|------|----------|----------|------|
| 全量备份 | 每日凌晨 2:00 | 30 天 | 异地对象存储 | 完整数据库备份 |
| 增量备份 | 每 4 小时 | 7 天 | 异地对象存储 | 仅备份变更数据 |
| 配置备份 | 每次变更时 | 90 天 | 版本控制系统 | 系统配置快照 |
| 手动备份 | 按需 | 永久（用户管理） | 异地对象存储 | 用户手动触发 |

**恢复策略：**

| 场景 | RTO（恢复时间目标） | RPO（恢复点目标） | 恢复方式 |
|------|---------------------|---------------------|----------|
| 全量恢复 | ≤ 4 小时 | ≤ 24 小时 | 从最近全量备份恢复 |
| 增量恢复 | ≤ 1 小时 | ≤ 4 小时 | 全量 + 增量备份恢复 |
| 配置恢复 | ≤ 15 分钟 | ≤ 1 小时 | 从配置快照恢复 |
| 单表恢复 | ≤ 30 分钟 | ≤ 4 小时 | 从备份中提取单表 |
