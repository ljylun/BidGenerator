# 19. 数据字典

> 本章定义GEO系统中使用的全部枚举值、状态码、类型码等数据字典。所有模块在设计和实现中必须统一引用本章定义的字典值，确保数据一致性和可维护性。

---

## 19.1 通用状态字典

### 19.1.1 账户状态（accountStatus）

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | 禁用 | 账户被管理员禁用，无法登录和使用任何功能 |
| 1 | 启用 | 账户正常使用状态 |
| 2 | 锁定 | 账户因安全原因被临时锁定（如连续登录失败），锁定时间到期后自动恢复为启用状态 |

### 19.1.2 内容状态（contentStatus）

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | 草稿 | 内容正在编辑中，尚未提交审核 |
| 1 | 待审核 | 内容已提交，等待审核人员审核 |
| 2 | 已发布 | 内容审核通过，已对外发布 |
| 3 | 已驳回 | 内容审核未通过，需修改后重新提交 |
| 4 | 已归档 | 内容已归档，不再对外展示但保留数据 |

### 19.1.3 知识库状态（knowledgeStatus）

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | 草稿 | 知识条目正在编辑中 |
| 1 | 待审核 | 知识条目已提交审核 |
| 2 | 已发布 | 知识条目审核通过，已在知识库中生效 |
| 3 | 已驳回 | 知识条目审核未通过 |
| 4 | 已归档 | 知识条目已归档，不再参与匹配但保留数据 |

### 19.1.4 Prompt状态（promptStatus）

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | 草稿 | Prompt正在编写和调试中 |
| 1 | 待测试 | Prompt已提交测试，等待测试执行 |
| 2 | 测试中 | Prompt正在进行效果测试和评估 |
| 3 | 已发布 | Prompt测试通过，已投入正式使用 |
| 4 | 待优化 | Prompt效果不理想，需要优化调整 |
| 5 | 已归档 | Prompt已废弃归档 |

### 19.1.5 诊断任务状态（diagnosisStatus）

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | 待配置 | 诊断任务已创建，尚未完成参数配置 |
| 1 | 待执行 | 诊断任务配置完成，等待调度执行 |
| 2 | 执行中 | 诊断任务正在执行数据采集和分析 |
| 3 | 已完成 | 诊断任务全部完成，报告已生成 |
| 4 | 部分失败 | 诊断任务部分平台采集失败，其余平台数据可用 |
| 5 | 失败 | 诊断任务全部平台采集失败 |
| 6 | 已归档 | 诊断任务已归档保存 |

### 19.1.6 Agent状态（agentStatus）

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | 草稿 | Agent正在配置和开发中 |
| 1 | 测试中 | Agent正在进行功能测试和效果验证 |
| 2 | 已发布 | Agent已发布上线 |
| 3 | 运行中 | Agent正在执行任务 |
| 4 | 已停止 | Agent已停止运行 |
| 5 | 待优化 | Agent效果需要优化，待调整 |

## 19.3 内容类型字典

### 19.3.1 内容类型（contentType）

| 值 | 名称 | 说明 |
|----|------|------|
| 1 | 文本 | 纯文本内容，如文章、问答、描述等 |
| 2 | 图片 | 图片内容，如信息图、图表、截图等 |
| 3 | 音频 | 音频内容，如播客、语音回答等 |
| 4 | 视频 | 视频内容，如短视频、讲解视频等 |
| 5 | 图文 | 图文混合内容，包含文字和图片的组合 |

### 19.3.2 内容来源类型（sourceType）

| 值 | 名称 | 说明 | 权威度权重 |
|----|------|------|-----------|
| 1 | 权威媒体 | 主流新闻媒体、知名媒体机构发布的内容 | 1.0 |
| 2 | 行业报告 | 行业研究机构发布的分析报告和白皮书 | 0.9 |
| 3 | 学术论文 | 学术期刊和会议发表的论文 | 0.95 |
| 4 | 政府网站 | 政府部门官方网站发布的信息 | 1.0 |
| 5 | 行业协会 | 行业协会和标准化组织发布的内容 | 0.85 |
| 6 | 企业官网 | 企业官方网站发布的内容 | 0.7 |

## 19.4 知识类型字典

### 19.4.1 知识类型（knowledgeType）

| 值 | 名称 | 说明 | 支持格式 |
|----|------|------|----------|
| 1 | 文本 | 纯文本知识条目 | TXT, MD, DOCX |
| 2 | 表格 | 结构化表格数据 | CSV, XLSX |
| 3 | 图片 | 图片知识内容 | PNG, JPG, SVG |
| 4 | 音频 | 音频知识内容 | MP3, WAV |
| 5 | 视频 | 视频知识内容 | MP4, AVI |

### 19.4.2 知识权限等级（knowledgePermissionLevel）

| 值 | 名称 | 说明 | 访问角色 |
|----|------|------|----------|
| 1 | 所有权限 | 所有用户均可查看和使用 | 全部用户 |
| 2 | 管理权限 | 仅管理员可编辑和管理 | 管理员 |
| 3 | 协作权限 | 管理员和协作者可编辑 | 管理员、协作者 |
| 4 | 使用权限 | 仅可查看和使用，不可编辑 | 普通用户 |

## 19.5 报表相关字典

### 19.5.1 报表周期（reportPeriod）

| 值 | 名称 | 说明 | 时间范围 |
|----|------|------|----------|
| 1 | 日报 | 每日生成一次报表 | 前一日00:00至23:59 |
| 2 | 周报 | 每周生成一次报表 | 周一至周日 |
| 3 | 月报 | 每月生成一次报表 | 上月1日至月末 |
| 4 | 季报 | 每季度生成一次报表 | 上季度首日至末日 |
| 5 | 年报 | 每年生成一次报表 | 上年1月1日至12月31日 |
| 6 | 自定义 | 用户自定义时间范围 | 用户指定起止时间 |

### 19.5.2 告警等级（alertLevel）

| 值 | 名称 | 颜色标识 | 说明 | 通知方式 |
|----|------|----------|------|----------|
| 1 | 信息 | 🔵 蓝色 | 一般性提示信息，无需立即处理 | 站内消息 |
| 2 | 警告 | 🟡 黄色 | 需要关注但非紧急的问题 | 站内消息 + 邮件 |
| 3 | 严重 | 🟠 橙色 | 重要问题，需要尽快处理 | 站内消息 + 邮件 + 企业微信/钉钉 |
| 4 | 紧急 | 🔴 红色 | 紧急问题，需要立即处理 | 全部通知渠道 + 电话 |
