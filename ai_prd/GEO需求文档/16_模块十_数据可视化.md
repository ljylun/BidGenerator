# 模块十：数据可视化与报表体系（M10）

> **优先级：P1**  
> **模块定位：** GEO 系统的"呈现层"，负责经营驾驶舱、GEO 效果看板和自定义报表，为运营决策提供直观的数据支撑。

---

## 16.1 功能清单

| 编号 | 功能名称 | 优先级 | 说明 |
|------|----------|--------|------|
| M10-F01 | 经营驾驶舱 | P1 | 全局经营数据一屏展示，包含核心 KPI、趋势图表、排名列表 |
| M10-F02 | GEO 效果看板 | P1 | 展示 GEO 各模块运行效果数据，如内容曝光量、引用率、排名变化 |
| M10-F03 | 内容效果看板 | P1 | 按内容维度展示效果指标，包括内容质量评分、传播数据、转化漏斗 |
| M10-F04 | 自定义报表 | P1 | 用户可自定义数据源、指标、维度、图表类型，生成个性化报表 |
| M10-F05 | 数据导出 | P1 | 支持将报表数据导出为 Excel、CSV、PDF 等格式 |
| M10-F06 | 定时报告推送 | P1 | 配置定时任务，自动将报表通过邮件或站内信推送给指定人员 |
| M10-F07 | 数据钻取 | P2 | 支持从汇总数据逐级下钻到明细数据，追溯数据源头 |
| M10-F08 | 报表权限管理 | P1 | 控制不同角色对报表的查看、编辑、导出权限 |

## 16.3 交互说明

| 交互项 | 触发条件 | 交互行为 | 备注 |
|--------|----------|----------|------|
| 查看报表 | 用户点击报表菜单或卡片 | 加载报表数据，渲染图表和表格；首次加载显示骨架屏，完成后渐入展示 | 支持浏览器前进后退 |
| 自定义配置 | 用户在报表编辑器中拖拽组件 | 实时预览效果；支持撤销/重做；配置变更自动保存草稿 | 每 30 秒自动保存 |
| 数据钻取 | 用户点击图表数据点或表格行 | 弹出下钻面板或跳转明细页，展示更细粒度的数据 | 支持最多 5 级下钻 |
| 数据导出 | 用户点击导出按钮 | 弹出格式选择（Excel/CSV/PDF），确认后异步生成文件，完成后提示下载 | 大数据量时提示预计等待时间 |
| 定时推送 | 用户配置定时任务 | 配置推送频率（日/周/月）、推送时间、接收人、推送格式；支持即时测试推送 | 推送失败自动重试 3 次 |
| 时间范围切换 | 用户切换时间选择器 | 全局联动刷新所有图表和 KPI 卡片数据 | 支持自定义时间范围 |
| 筛选联动 | 用户修改筛选条件 | 当前页面内所有组件按新筛选条件联动刷新 | 筛选条件支持保存为模板 |
| 图表交互 | 用户 hover 图表数据点 | 显示 tooltip，包含指标名称、数值、同比/环比变化 | 支持图例点击隐藏/显示 |

## 16.4 错误处理

| 错误场景 | 错误码 | 处理策略 | 用户提示 |
|----------|--------|----------|----------|
| 数据加载失败 | M10-E01 | 自动重试 2 次，间隔 3 秒；仍失败则展示错误页 | "数据加载失败，请检查网络后重试" |
| 报表配置错误 | M10-E02 | 高亮错误配置项，展示错误详情和修复建议 | "报表配置有误：[具体错误描述]" |
| 导出失败 | M10-E03 | 记录导出失败日志，提供重试按钮 | "导出失败，请重试或缩小数据范围" |
| 权限不足 | M10-E04 | 隐藏无权限的报表和操作按钮 | "您没有查看该报表的权限，请联系管理员" |
| 图表渲染失败 | M10-E05 | 降级展示为数据表格 | "图表渲染异常，已切换为表格视图" |
| 定时推送失败 | M10-E06 | 连续 3 次失败后暂停任务并告警 | "定时推送已暂停，请检查配置" |
| 数据超时 | M10-E07 | 超过 30 秒未返回则中断请求 | "查询超时，建议缩小时间范围或减少数据量" |
| 存储空间不足 | M10-E08 | 提示用户清理历史报表 | "报表存储已达上限，请清理不需要的报表" |

### 16.5.2 报表模板引擎

| 组件 | 说明 |
|------|------|
| 模板存储 | 报表模板以 JSON Schema 格式存储于数据库，支持版本管理 |
| 模板解析 | 前端解析 JSON Schema 动态渲染图表、表格、筛选器等组件 |
| 模板市场 | 提供预设模板库（经营分析、效果分析、内容分析等），支持一键应用 |
| 模板共享 | 用户可将自定义模板发布为公共模板，供其他用户使用 |

### 16.5.3 数据可视化组件库

| 组件类型 | 支持图表 | 说明 |
|----------|----------|------|
| 趋势图 | 折线图、面积图、阶梯图 | 支持多系列、双坐标轴、数据标注 |
| 对比图 | 柱状图、条形图、雷达图 | 支持堆叠、分组、排序 |
| 分布图 | 饼图、环形图、散点图、气泡图 | 支持图例交互、数据标签 |
| 表格 | 数据表格、透视表格 | 支持排序、筛选、分页、列拖拽 |
| 地图 | 区域地图、热力图 | 支持区域下钻、数据标注 |
| KPI 卡片 | 指标卡、进度卡、对比卡 | 支持同比/环比、目标达成率 |

### 16.5.4 定时推送机制

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 定时调度  │───▶│ 报表生成  │───▶│ 格式转换  │───▶│ 推送分发  │
│ (Cron)   │    │ (渲染)   │    │ (PDF/Excel)│   │ (邮件/站内信)│
└──────────┘    └──────────┘    └──────────┘    └──────────┘
      │                                               │
      │              ┌──────────┐                     │
      └─────────────▶│ 推送日志  │◀────────────────────┘
                     └──────────┘
```

- 调度引擎：基于 Quartz / XXL-JOB 实现分布式定时任务
- 推送渠道：邮件（SMTP）、站内消息、企业微信/钉钉（Webhook）
- 失败策略：首次失败立即重试，第二次间隔 5 分钟，第三次间隔 30 分钟；连续 3 次失败暂停任务并告警

### 16.5.5 权限控制模型

| 权限粒度 | 说明 |
|----------|------|
| 报表级权限 | 控制用户能否查看、编辑、删除、导出某报表 |
| 数据级权限 | 控制用户能看到的数据范围（如仅看本部门数据） |
| 操作级权限 | 控制用户能否执行特定操作（如导出、定时推送） |
