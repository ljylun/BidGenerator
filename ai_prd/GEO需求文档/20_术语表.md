# 20 术语表

本章汇总了本需求文档中涉及的核心术语与缩写，便于读者快速查阅与理解。

| 序号 | 术语 | 全称 | 说明 |
|------|------|------|------|
| 1 | GEO | Generative Engine Optimization | 生成式引擎优化，指针对大语言模型（LLM）驱动的搜索和问答系统进行内容优化，使品牌或产品在 AI 生成的回答中获得可见性与引用的策略。 |
| 2 | AIVO | AI Visibility Optimization | AI 可见性优化，通过系统化手段提升品牌在 AI 平台（如 ChatGPT、Perplexity、Gemini 等）中的曝光度与正面提及率。 |
| 3 | T-GEO™ | 五层认知工程模型 | 将 GEO 实施划分为数据层、语义层、认知层、决策层、反馈层五个层次，形成完整的认知工程闭环。 |
| 4 | E-E-A-T | Experience-Expertise-Authoritativeness-Trustworthiness | 经验、专业度、权威性、可信度，Google 评估内容质量的核心框架，在 GEO 语境下同样适用于衡量 AI 系统对内容来源的信任判断。 |
| 5 | EEAT | E-E-A-T 的另一种缩写形式 | 与 E-E-A-T 同义，部分文献中省略连字符的写法，本文档中两者等价使用。 |
| 6 | LLM | Large Language Model | 大语言模型，基于大规模文本数据训练的深度学习模型（如 GPT-4、Claude、Gemini 等），能够理解、生成和处理自然语言，是 GEO 优化的核心对象。 |
| 7 | NER | Named Entity Recognition | 命名实体识别，NLP 核心技术之一，用于从非结构化文本中识别并分类人名、地名、组织名、产品名等实体，在 GEO 中用于品牌实体提取与关联分析。 |
| 8 | RAG | Retrieval-Augmented Generation | 检索增强生成，通过先检索相关文档片段再输入 LLM 生成回答的架构，是当前 AI 平台回答用户问题的主流技术路径，也是 GEO 内容优化的关键切入点。 |
| 9 | MAS | Multi-Agent System | 多智能体系统，由多个自主智能体协同工作的架构模式，在本系统中用于实现数据采集、分析、优化、监控等多环节的自动化协作。 |
| 10 | CDP | Customer Data Platform | 客户数据平台，统一收集、整合和管理客户第一方数据的系统，为 GEO 策略提供用户行为与偏好洞察。 |
| 11 | DSP | Demand-Side Platform | 需求方平台，用于程序化广告投放的买方平台，在 GEO 生态中可用于 AI 搜索场景下的付费可见性管理。 |
| 12 | DMP | Data Management Platform | 数据管理平台，用于收集、组织和激活第三方受众数据，为 GEO 策略提供外部数据补充与人群扩展能力。 |
| 13 | pCTR | Predicted Click-Through Rate | 预测点击率，利用机器学习模型预估用户点击某条内容或广告的概率，在 GEO 中用于评估 AI 推荐内容的吸引力。 |
| 14 | pCVR | Predicted Conversion Rate | 预测转化率，利用机器学习模型预估用户完成目标转化行为的概率，在 GEO 中用于衡量 AI 引流内容的商业价值。 |
| 15 | RaaS | Results as a Service | 结果即服务，一种按效果付费的云服务模式，在本系统中指按 GEO 优化效果（如 AI 引用率提升）计费的交付模式。 |
| 16 | One-ID | 统一用户身份标识 | 跨系统、跨渠道的唯一用户标识体系，用于打通 CDP、DMP 等多源数据，实现用户全链路行为追踪与统一画像。 |
| 17 | RBAC | Role-Based Access Control | 基于角色的访问控制，通过为用户分配角色来控制其对系统资源的访问权限，是本系统权限管理的基础模型。 |
| 18 | ABAC | Attribute-Based Access Control | 基于属性的访问控制，通过评估用户属性、资源属性、环境条件等动态决定访问权限，用于实现更细粒度的数据访问控制。 |
| 19 | RTO | Recovery Time Objective | 恢复时间目标，系统从故障发生到恢复正常运行所允许的最大时间，本系统要求核心模块 RTO ≤ 4 小时。 |
| 20 | RPO | Recovery Point Objective | 恢复点目标，系统故障时允许丢失数据的最大时间窗口，本系统要求核心数据 RPO ≤ 1 小时。 |
| 21 | CMMI | Capability Maturity Model Integration | 能力成熟度模型集成，用于评估和改进组织过程能力的框架，在本系统运维与质量管理中作为成熟度评估参考。 |
| 22 | SEO | Search Engine Optimization | 搜索引擎优化，传统上指针对 Google、百度等搜索引擎的有机排名优化，GEO 是 SEO 在 AI 搜索时代的新延伸。 |
| 23 | SERP | Search Engine Results Page | 搜索引擎结果页，用户搜索后展示的排名结果页面，在 GEO 语境下也包含 AI 搜索工具生成的回答界面。 |
| 24 | NLP | Natural Language Processing | 自然语言处理，计算机科学与 AI 的分支领域，涵盖文本理解、生成、翻译、情感分析等技术，是 GEO 内容分析的核心技术基础。 |
| 25 | API | Application Programming Interface | 应用程序编程接口，用于不同软件系统间标准化通信和数据交换的协议集合，本系统通过 API 与多个外部平台对接。 |
| 26 | OAuth | Open Authorization | 开放授权标准，允许用户授权第三方应用访问其资源而无需暴露密码，在本系统用于外部平台安全接入与单点登录。 |
| 27 | MFA | Multi-Factor Authentication | 多因素认证，通过结合两种或以上验证因素（密码、短信、生物特征等）来增强账户安全性，本系统对管理后台强制启用 MFA。 |
