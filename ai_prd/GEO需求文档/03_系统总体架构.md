# 3. 系统总体架构

## 3.1 架构分层

```
┌─────────────────────────────────────────────────────────────────┐
│                        用户交互层                                │
│  Web工作台 │ 移动端 │ 小程序 │ API开放平台 │ 第三方集成          │
├─────────────────────────────────────────────────────────────────┤
│                        场景应用层                                │
│  品牌诊断 │ Prompt管理 │ 知识库 │ 内容生产 │ 数据看板 │ Agent    │
├─────────────────────────────────────────────────────────────────┤
│                        业务服务层                                │
│  认知诊断服务 │ 语义工程服务 │ 知识库服务 │ 内容服务 │ 优化服务  │
├─────────────────────────────────────────────────────────────────┤
│                        数据中台层                                │
│  知识图谱引擎 │ CDP │ 数据仓库 │ 实时计算 │ 搜索引擎          │
├─────────────────────────────────────────────────────────────────┤
│                        基础设施层                                │
│  大模型能力 │ NLP引擎 │ 向量数据库 │ 图数据库 │ 对象存储        │
└─────────────────────────────────────────────────────────────────┘
```

## 3.2 技术选型要求

| 技术领域 | 选型方向 | 备注 |
|----------|----------|------|
| 大语言模型 | 支持多模型接入（自研+开源），千亿参数级优先 | 需支持模型切换和A/B测试 |
| 知识图谱 | 图数据库（Neo4j/自研），支持千万级节点 | 需支持实时查询和增量更新 |
| 向量数据库 | Milvus/Pinecone/自研，支持语义检索 | 需支持混合检索（向量+关键词） |
| 实时计算 | Flink/Spark Streaming | 算法监测、效果追踪需要实时性 |
| 数据存储 | MySQL（业务）+ Elasticsearch（搜索）+ OSS（文件） | 根据数据类型选择适配存储 |

## 3.3 数据流架构

### 3.3.1 数据采集流

```
AI平台API → 数据采集服务 → 数据清洗 → 数据仓库 → 分析引擎
                                    ↓
                              实时计算 → 告警服务
```

### 3.3.2 内容生产流

```
品牌信息 → 知识库检索 → Prompt引擎 → LLM生成 → 内容审核 → 信源投喂
    ↑                                              ↓
    └──────── 效果反馈 ← 效果追踪 ← AI平台引用数据 ←┘
```

### 3.3.3 智能体执行流

```
用户指令 → Agent调度器 → 任务分解 → 子Agent执行 → 结果汇总
                ↓                        ↑
           知识库/Prompt库 ──────── 工具调用
```

## 3.4 部署架构

### 3.4.1 微服务划分

| 微服务 | 职责 | 核心依赖 |
|--------|------|----------|
| 诊断服务 | 品牌AI可见性诊断 | AI平台API、NLP引擎 |
| 语义服务 | Prompt管理和语义对齐 | LLM、向量数据库 |
| 知识库服务 | 知识库管理和检索 | ES、向量数据库、图数据库 |
| 内容服务 | 内容生产和发布 | LLM、信源API |
| 数据服务 | 数据看板和分析 | 数据仓库、实时计算 |
| Agent服务 | Agent构建和执行 | LLM、MAS框架 |
| CDP服务 | 用户数据管理 | 数据仓库、ID Mapping |
| 图谱服务 | 知识图谱构建和查询 | 图数据库、NLP |
| 系统服务 | 账号权限和配置 | 配置中心、日志系统 |

### 3.4.2 高可用设计

| 组件 | 高可用方案 |
|------|-----------|
| 应用服务 | 多实例部署 + 负载均衡 |
| 数据库 | 主从复制 + 读写分离 |
| 缓存 | Redis集群 |
| 消息队列 | Kafka集群 |
| 文件存储 | 跨区域冗余 |
| LLM调用 | 多模型降级 + 重试机制 |
