## 2.4 权限模型说明

本系统采用 **RBAC + ABAC 混合权限模型**：

### RBAC（基于角色的访问控制）

- 通过角色分配功能权限
- 一个用户可拥有多个角色
- 角色权限取并集

### ABAC（基于属性的访问控制）

- 通过数据属性控制数据权限
- 支持按组织、部门、业务线等维度隔离数据
- 数据权限策略可自定义配置

### 权限层级

```
系统级权限（系统管理员）
  └── 组织级权限（业务管理员）
        └── 部门级权限（部门负责人）
              └── 个人级权限（普通用户）
```

### 高危操作二次确认

以下操作需二次确认或MFA验证：

| 操作类型 | 确认方式 |
|----------|----------|
| 删除知识库/Prompt库 | 弹窗确认 + 输入确认词 |
| 修改系统配置 | MFA验证 |
| 批量导出数据 | 弹窗确认 |
| 用户权限变更 | 弹窗确认 |
| 知识库发布 | 弹窗确认 |
