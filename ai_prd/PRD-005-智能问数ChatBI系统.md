## 1. 产品概述

### 1.1 背景与问题

| 维度 | 现状 |
|------|------|
| **痛点来源** | 全业务线（运营、采购、督导、财务等） |
| **当前方式** | 业务人员提需 → 数据分析师 SQL 查询 → Excel 回复，平均 1-3 天 |
| **核心问题** | 数据查询门槛高、响应慢、口径不统一、分析师资源瓶颈 |
| **业务影响** | 业务决策等待数据支持，时效性差；数据口径不一致导致决策分歧 |
| **量化损失** | 数据分析师 60% 时间花在重复查询上；业务人员平均等待 1.5 天 |

### 1.2 产品定义

**一句话描述**：业务人员用自然语言提问，系统自动生成 SQL、执行查询、返回可视化结果，实现"人人都是数据分析师"。

**产品愿景**：构建企业级自然语言数据查询平台，让业务人员自助获取数据洞察，将数据查询时效从"天级"降至"秒级"。

**产品载体**：本产品为运行在钉钉平台上的**钉钉AI表格应用**，利用钉钉AI表格的多维表格能力、自动化流程、AI字段识别、权限管理等原生功能，实现数据查询结果的结构化存储、分析与协作。

### 1.3 目标用户

| 角色 | 用户画像 | 使用场景 | 核心诉求 | 使用频率 |
|------|----------|----------|----------|----------|
| 业务运营 | 25-40 岁，业务决策 | 日常经营分析 | 快速获取业务数据 | 每日 |
| 管理层 | 35-50 岁，战略决策 | 经营复盘 | 全局经营指标 | 每周 |
| 数据分析师 | 25-35 岁，技术支持 | 数据查询 | 减少重复劳动 | 每日 |
| 财务人员 | 30-45 岁，财务分析 | 财务数据查询 | 快速获取财务指标 | 每周 |

## 2. 业务流程

### 2.1 智能问数主流程

```
业务人员用自然语言提问
        │
        ▼
NL2SQL 模型解析
  ├─ 理解业务意图
  ├─ 识别指标和维度
  └─ 映射到数据表字段
        │
        ▼
SQL 生成与校验
  ├─ 生成 SQL 语句
  ├─ 语法校验
  └─ 安全检查（防注入）
        │
        ▼
查询执行
  ├─ 提交到数据库
  ├─ 等待执行结果
  └─ 超时处理（> 30s 提示）
        │
        ▼
结果处理
  ├─ 数据表格展示
  ├─ 自动生成图表（柱状图/折线图/饼图）
  └─ 自然语言总结
        │
        ▼
结果存储至钉钉AI表格
  ├─ 问题归档
  └─ 结果缓存（相同问题直接返回）
```

### 2.2 数据权限流程

```
用户提问
        │
        ▼
身份识别
  ├─ 角色（运营/管理层/分析师）
  └─ 部门/区域
        │
        ▼
权限过滤
  ├─ 可访问的表
  ├─ 可查看的字段
  └─ 可查询的数据范围
        │
        ▼
SQL 改写（加入权限过滤条件）
        │
        ▼
执行查询（仅返回权限内数据）
```

#### 核心表结构（备用关系型数据库方案）

```sql
-- 查询记录表
CREATE TABLE query_log (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    query_no        VARCHAR(50) UNIQUE NOT NULL COMMENT '查询编号',
    user_id         VARCHAR(50) NOT NULL COMMENT '用户ID',
    user_question   TEXT NOT NULL COMMENT '用户问题',
    generated_sql   TEXT COMMENT '生成SQL',
    query_status    VARCHAR(20) COMMENT 'SUCCESS/FAILED/TIMEOUT',
    execution_time  INT COMMENT '查询耗时(ms)',
    result_rows     INT COMMENT '返回行数',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user_time (user_id, created_at)
);

-- 热门问题表
CREATE TABLE hot_question (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    question_text   TEXT NOT NULL COMMENT '问题文本',
    category        VARCHAR(50) COMMENT '问题分类',
    query_count     INT DEFAULT 0 COMMENT '查询次数',
    avg_time        INT COMMENT '平均耗时(ms)',
    priority        INT DEFAULT 0 COMMENT '推荐优先级',
    status          TINYINT DEFAULT 1,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 指标字典表
CREATE TABLE metric_dictionary (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    metric_name     VARCHAR(200) NOT NULL COMMENT '指标名称',
    metric_code     VARCHAR(100) UNIQUE NOT NULL COMMENT '指标编码',
    definition      TEXT COMMENT '指标定义',
    formula         TEXT COMMENT '计算公式',
    data_source     VARCHAR(200) COMMENT '数据源',
    update_freq     VARCHAR(20) COMMENT 'REALTIME/DAILY/WEEKLY',
    owner           VARCHAR(50) COMMENT '负责人',
    status          TINYINT DEFAULT 1,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 4.3 API 规格

#### 自然语言查询 API

```
POST /api/v1/chatbi/query
Content-Type: application/json

请求参数：
{
  "question": "今天成都区域的销售额是多少？",
  "user_id": "user123",
  "context": {
    "date_range": "today",
    "region": "成都"
  }
}

响应：
{
  "code": 200,
  "data": {
    "query_id": "q001",
    "question": "今天成都区域的销售额是多少？",
    "sql": "SELECT SUM(sales_amount) FROM sales WHERE date = '2026-06-12' AND region = '成都'",
    "result": {
      "columns": ["销售额"],
      "rows": [["125,680.00"]]
    },
    "chart": {
      "type": "number",
      "title": "成都区域今日销售额",
      "value": 125680.00
    },
    "summary": "今日成都区域销售额为 125,680 元，较昨日增长 5.2%",
    "execution_time": 1200
  }
}
```

### 4.4 钉钉AI表格集成方案

#### 4.4.1 钉钉AI表格应用架构

本产品作为钉钉AI表格应用运行，利用钉钉开放平台提供的以下核心能力：

| 能力模块 | 用途 | 实现方式 |
|----------|------|----------|
| 多维表格 | 数据存储与管理 | 使用钉钉AI表格存储查询记录和指标字典 |
| 自动化流程 | 业务逻辑触发 | 配置自动化规则，实现查询结果通知 |
| 权限管理 | 数据访问控制 | 配置表格级、行级、列级权限 |
| 消息通知 | 推送提醒 | 通过钉钉机器人推送查询结果 |
| 连接器 | 外部系统集成 | 通过连接器调用外部AI服务 |

#### 4.4.2 钉钉开放平台集成

**钉钉应用配置**：
- 应用类型：企业内部应用
- 运行平台：钉钉AI表格
- 权限范围：
  - `dingtalk:app:table:read` - 表格读取
  - `dingtalk:app:table:write` - 表格写入
  - `dingtalk:user:readonly` - 用户基本信息读取
  - `dingtalk:message:send_as_bot` - 消息发送

#### 4.4.3 前端技术适配

**运行环境要求**：
- 运行平台：钉钉客户端（iOS/Android）内置浏览器
- 技术框架：钉钉AI表格小程序框架（基于钉钉小程序技术栈）
- 兼容性要求：
  - iOS 13.0+
  - Android 8.0+
  - 钉钉客户端版本 6.5.0+
