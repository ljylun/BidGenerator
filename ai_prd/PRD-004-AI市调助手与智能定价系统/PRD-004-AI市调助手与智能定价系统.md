## 1. 产品概述

### 1.1 背景与问题

| 维度 | 现状 |
|------|------|
| **痛点来源** | 单品运营、采购部 |
| **当前方式** | 每日市调依靠人工拍照、手写记录；定价依赖经验和"脑子里的记忆" |
| **核心问题** | 数据非结构化、无法复盘历史决策逻辑、缺乏竞品价格趋势分析 |
| **业务影响** | 定价策略盲目，无法实时响应竞品价格变化，毛利率损失 1-2% |
| **量化损失** | 采购人员每周花 1-2 天整理竞品数据；定价偏差导致年损失约 30-50 万元 |

### 1.2 产品定义

**一句话描述**：市调人员拍摄竞品价签后，AI 自动提取并结构化存储至钉钉AI表格，建立"竞品价格雷达"；结合成本价、竞品价和库存压力，自动推荐最优零售价区间，实现数据驱动的智能定价。

**产品愿景**：构建从"数据采集 → 价格分析 → 智能定价"的完整闭环，实现"一品一策"的精细化定价。

**产品载体**：本产品为运行在钉钉平台上的**钉钉AI表格应用**，利用钉钉AI表格的多维表格能力、自动化流程、AI字段识别、权限管理等原生功能，实现市调数据的采集、存储、分析与协作。

### 1.3 目标用户

| 角色 | 用户画像 | 使用场景 | 核心诉求 | 使用频率 |
|------|----------|----------|----------|----------|
| 市调人员 | 25-35 岁，一线执行 | 每日外出市调 | 快速采集、自动记录 | 每日 |
| 单品运营 | 28-40 岁，数据分析 | 定价决策 | 实时竞品价格、建议价格 | 每日 |
| 采购人员 | 30-45 岁，成本管控 | 成本与售价分析 | 成本价与售价联动 | 每周 |
| 管理层 | 40+ 岁，战略视角 | 价格策略 | 全局价格竞争力看板 | 每月 |

## 2. 业务流程

### 2.1 拍照市调流程

```
市调人员到达竞对门店
        │
        ▼
钉钉AI表格应用拍摄价签照片
        │
        ▼
AI OCR 识别（qwen-vl-ocr）
  ├─ 提取：商品名称、规格、价格、促销信息
  └─ 结构化存入钉钉AI表格
        │
        ▼
自动关联历史价格数据
  ├─ 与上次市调价格比对
  ├─ 计算价格变动幅度
  └─ 检测异常波动
        │
        ▼
生成比价报告 → 推送至运营人员
```

### 2.2 智能定价流程

```
每日定价任务触发（8:00）
        │
        ▼
数据汇聚
  ├─ 当日成本价（真实配送价，来源：李富美系统）
  ├─ 竞品价格（市调数据，来源：PRD-001）
  ├─ 库存周转压力（来源：库存系统）
  ├─ 促销计划（来源：营销日历）
  ├─ 历史销售弹性（来源：销售数据）
  └─ 品类毛利率目标（来源：财务设定）
        │
        ▼
定价模型计算
  ├─ 规则引擎：基础定价逻辑
  ├─ ML 模型：价格弹性优化（后期）
  └─ 输出：建议零售价区间 [最低价, 建议价, 最高价]
        │
        ▼
运营人员审核确认
  ├─ 采纳建议 → 价格生效
  └─ 调整价格 → 记录调整原因
        │
        ▼
价格同步至 POS / 线上平台
```

### 3.3 智能定价模型

**定价因子**：

| 因子 | 数据来源 | 影响权重 | 更新频率 |
|------|----------|----------|----------|
| 成本价 | 供应链系统（李富美"真实配送价"） | 40% | 每日 |
| 竞品价格 | 市调数据（PRD-001） | 25% | 每日 |
| 库存周转压力 | 库存系统 | 15% | 每日 |
| 价格弹性 | 历史销售数据 | 10% | 每周 |
| 促销计划 | 营销日历 | 10% | 每周 |

**定价公式**：
```
建议售价 = 成本价 × (1 + 目标毛利率) × 竞争系数 × 库存系数

其中：
- 目标毛利率 = 品类默认值 + 人工调整
- 竞争系数 = f(本品价格/竞品价格)
  - 竞品价格 < 本品价格 × 0.9 → 系数 = 0.95（降价竞争）
  - 竞品价格 > 本品价格 × 1.1 → 系数 = 1.05（适度提价）
  - 其他 → 系数 = 1.0
- 库存系数 = f(库存周转天数)
  - 周转天数 > 7 → 系数 = 0.95（降价促销）
  - 周转天数 < 2 → 系数 = 1.05（适度提价）
  - 其他 → 系数 = 1.0
```

**定价规则示例**：

| 规则 | 条件 | 动作 |
|------|------|------|
| 保底毛利 | 毛利率 < 15% | 自动设为成本价 × 1.18 |
| 竞品跟价 | 竞品降价 > 15% | 建议跟进降价 |
| 库存清仓 | 周转天数 > 10 且保质期 < 3 天 | 建议特价清仓 |
| 新品定价 | 无历史数据 | 参考竞品价格定价 |

#### 核心表结构（备用关系型数据库方案）

```sql
-- 竞品商品表
CREATE TABLE competitor_product (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    brand_id        BIGINT NOT NULL COMMENT '竞对品牌ID',
    product_name    VARCHAR(500) NOT NULL COMMENT '商品名称',
    spec            VARCHAR(200) COMMENT '规格',
    category        VARCHAR(200) COMMENT '品类',
    our_product_id  BIGINT COMMENT '对应本品商品ID',
    status          TINYINT DEFAULT 1,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 竞品价格记录表
CREATE TABLE competitor_price (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    product_id      BIGINT NOT NULL COMMENT '竞品商品ID',
    store_id        BIGINT NOT NULL COMMENT '竞对门店ID',

    member_price    DECIMAL(10, 2) COMMENT '会员价',

    INDEX idx_product_date (product_id, price_date)

-- 定价建议表
CREATE TABLE pricing_suggestion (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    product_id      BIGINT NOT NULL COMMENT '本品商品ID',
    suggest_date    DATE NOT NULL COMMENT '建议日期',
    cost_price      DECIMAL(10, 2) COMMENT '成本价',
    competitor_avg  DECIMAL(10, 2) COMMENT '竞品均价',
    current_price   DECIMAL(10, 2) COMMENT '当前售价',
    suggested_min   DECIMAL(10, 2) COMMENT '建议最低价',

    confirmed_by    VARCHAR(50) COMMENT '确认人',
    confirmed_at    DATETIME,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_product_date (product_id, suggest_date)
);

-- 价格弹性分析表
CREATE TABLE price_elasticity (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    product_id      BIGINT NOT NULL COMMENT '商品ID',
    analysis_date   DATE NOT NULL COMMENT '分析日期',
    price_change_pct DECIMAL(5, 4) COMMENT '价格变动百分比',
    sales_change_pct DECIMAL(5, 4) COMMENT '销量变动百分比',
    elasticity      DECIMAL(5, 4) COMMENT '弹性系数',
    confidence      DECIMAL(5, 4) COMMENT '置信度',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);
```
