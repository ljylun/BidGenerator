## 1. 模块概述

### 1.1 定位

库存校准与毛利核算模块基于动态损耗计算结果，自动修正库存数据，并基于真实损耗数据进行毛利自动计算，解决传统固定 3% 损耗导致的毛利失真问题。

### 1.2 目标

| 指标 | 目标值 |
|------|--------|
| 库存校准精度 | 偏差 ≤ 0.5% |
| 毛利核算精度 | 基于真实损耗，偏差 ≤ 0.3% |
| 核算时效 | 每日完成全量核算 |
| 毛利提升 | 真实损耗核算后，毛利率预计提升 2-3 个百分点 |

### 1.3 用户角色

| 角色 | 使用场景 | 核心诉求 |
|------|----------|----------|
| 财务人员 | 月度核算 | 真实、动态的毛利数据 |
| 运营管理层 | 全局库存健康度 | 库存周转率看板 |

## 2. 功能需求

### 2.1 功能清单

| 功能ID | 功能名称 | 优先级 | 描述 |
|--------|----------|--------|------|
| F-004 | 库存校准 | P0 | 自动修正库存数据 |
| F-005 | 毛利核算 | P0 | 基于真实损耗的毛利自动计算 |

### 2.2 计算逻辑

**库存校准**：
```
系统库存 = 账面库存 - 累计动态损耗
```

**毛利核算**：
```
毛利 = 售价 - 配送价 - 动态损耗金额
毛利率 = 毛利 / 售价 × 100%
```

### 2.3 告警规则

- 毛利率低于阈值时实时告警，通知财务和运营
- 库存异常（负值/过高）时告警

## 3. 数据模型

本模块复用 M3 动态损耗计算模块的数据表（dynamic_loss、category_loss_config），以下为新增关联视图：

### 3.1 库存校准视图

```sql
CREATE VIEW v_stock_calibration AS
SELECT
    s.store_id,
    s.product_id,
    s.book_stock AS 账面库存,
    COALESCE(SUM(d.loss_amount), 0) AS 累计损耗金额,
    s.book_stock - COALESCE(
        SUM(d.dynamic_loss_rate * s.book_stock), 0
    ) AS 校准后库存,
    s.updated_at
FROM stock s
LEFT JOIN dynamic_loss d ON s.store_id = d.store_id
    AND s.product_id = d.product_id
    AND d.loss_date >= DATE_SUB(CURDATE(), INTERVAL 7 DAY)
GROUP BY s.store_id, s.product_id, s.book_stock, s.updated_at;
```

### 3.2 毛利核算视图

```sql
CREATE VIEW v_profit_calculation AS
SELECT
    d.store_id,
    d.product_id,
    p.sale_price AS 售价,
    p.delivery_price AS 配送价,
    d.loss_amount AS 动态损耗金额,
    p.sale_price - p.delivery_price - d.loss_amount AS 毛利,
    (p.sale_price - p.delivery_price - d.loss_amount) / p.sale_price * 100 AS 毛利率
FROM dynamic_loss d
JOIN product p ON d.product_id = p.id;
```
