## 1. 模块概述

### 1.1 定位

监控与预警模块持续跟踪预测准确率，监控库存健康状态，在预测缺货、滞销风险、毛利率异常等场景下自动触发告警，确保业务异常及时发现和处理。

### 1.2 目标

| 指标 | 目标值 |
|------|--------|
| 预测准确率监控 | MAPE ≤ 25%（加权平均） |
| 告警延迟 | ≤ 1 小时 |
| 告警覆盖率 | 缺货/滞销/毛利异常 100% 覆盖 |
| 误报率 | ≤ 5% |

### 1.3 用户角色

| 角色 | 使用场景 | 核心诉求 |
|------|----------|----------|
| 店长 | 门店运营 | 缺货/滞销风险告警 |
| 财务人员 | 毛利监控 | 毛利率异常下降告警 |
| 运营管理层 | 全局监控 | 预测准确率趋势 |

## 2. 功能需求

### 2.1 功能清单

| 功能ID | 功能名称 | 优先级 | 描述 |
|--------|----------|--------|------|
| F-006 | 预测准确率监控 | P1 | 持续跟踪预测准确率 |
| F-007 | 异常预警 | P1 | 预测缺货/滞销风险告警 |

### 2.2 告警场景

| 告警类型 | 触发条件 | 告警对象 | 告警方式 |
|----------|----------|----------|----------|
| 缺货风险 | 预测库存 < 安全库存 | 店长 | 钉钉消息 |
| 滞销风险 | 预测销量 < 阈值 & 库存 > 上限 | 店长 | 钉钉消息 |
| 毛利异常 | 毛利率 < 阈值 | 财务 + 运营 | 钉钉消息 |
| 预测偏差 | MAPE > 30% | 数据团队 | 钉钉消息 |
| 任务异常 | 预测任务失败/超时 | 运维 | 钉钉消息 |

### 2.3 预测准确率指标

| 指标 | 定义 | 目标值 |
|------|------|--------|
| MAPE | 平均绝对百分比误差 | ≤ 25%（加权平均） |
| RMSE | 均方根误差 | 品类差异化 |
| 偏差率 | 预测值与实际值的系统性偏差 | ≤ 5% |
| 覆盖率 | 可预测 SKU 占总 SKU 比例 | ≥ 80% |

## 3. 数据模型

### 3.1 预测准确率统计表（钉钉AI表格）

| 字段名 | 字段类型 | 说明 |
|--------|----------|------|
| 统计日期 | 日期 | 统计日期 |
| 门店 | 关联 | 关联门店表（空表示全国） |
| 品类 | 关联 | 关联品类表（空表示全部） |
| 预测总数 | 数字 | 预测总数 |
| MAPE | 数字 | 平均绝对百分比误差 |
| RMSE | 数字 | 均方根误差 |
| 准确率 | 数字 | 1-MAPE |
| 创建时间 | 系统字段 | 自动记录 |

### 3.2 核心表结构（关系型数据库方案）

```sql
CREATE TABLE forecast_accuracy (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    stat_date       DATE NOT NULL COMMENT '统计日期',
    store_id        BIGINT COMMENT '门店ID（NULL表示全国）',
    category_id     BIGINT COMMENT '品类ID（NULL表示全部）',
    total_forecasts INT COMMENT '预测总数',
    mape            DECIMAL(5, 4) COMMENT '平均绝对百分比误差',
    rmse            DECIMAL(10, 4) COMMENT '均方根误差',
    accuracy_rate   DECIMAL(5, 4) COMMENT '准确率（1-MAPE）',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_date_store_category (stat_date, store_id, category_id)
);
```

## 4. 运维巡检

| 巡检项 | 频率 | 正常标准 | 异常处理 |
|--------|------|----------|----------|
| 预测任务完成率 | 每日 | 100% | 检查调度和模型服务 |
| 预测准确率 | 每日 | MAPE ≤ 25% | 检查数据质量和模型 |
| 订货建议推送 | 每日 | 7:00 前完成 | 检查钉钉接口 |
| 损耗计算任务 | 每日 | 100% 完成 | 检查数据源和计算逻辑 |
| 模型训练任务 | 每周 | 成功完成 | 检查训练数据和资源 |
