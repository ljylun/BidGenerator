## 1. 模块概述

### 1.1 定位

数据管理模块负责历史数据的导入、清洗、校验，以及品类损耗参数、门店信息等基础数据的管理维护，为其他模块提供高质量的数据基础。

### 1.2 目标

| 指标 | 目标值 |
|------|--------|
| 历史数据迁移 | 3-5 年历史销量数据 |
| 数据清洗自动化 | ≥ 95% 自动清洗，≤ 5% 人工处理 |
| 数据质量校验 | 必填项完整率 ≥ 99%，格式正确率 ≥ 98% |
| 基础数据维护 | 品类参数、门店信息 CRUD |

### 1.3 用户角色

| 角色 | 使用场景 | 核心诉求 |
|------|----------|----------|
| 数据管理员 | 数据迁移 | 历史数据导入、清洗 |
| 运营人员 | 基础数据维护 | 品类参数、门店信息管理 |

## 2. 功能需求

### 2.1 功能清单

| 功能ID | 功能名称 | 优先级 | 描述 |
|--------|----------|--------|------|
| F-010 | 数据管理 | P0 | 历史数据导入、清洗、校验 |

### 2.2 数据源清单

| 数据源 | 数据类型 | 更新频率 | 说明 |
|--------|----------|----------|------|
| ERP 系统 | 历史销量、库存数据 | 每日 | 3-5 年数据 |
| 气象 API | 天气数据 | 每日 | 实时 + 未来 7 天预报 |
| 节假日日历 | 节假日/调休信息 | 每年更新 | 含特殊日期 |
| 营销日历 | 促销活动信息 | 每周 | 品鉴会/满减等 |
| 门店画像 | 区域特征/人流量 | 每季 | 商圈类型 |

### 2.3 数据清洗规则

| 清洗项 | 规则 | 处理方式 |
|--------|------|----------|
| 缺失值 | 销量为空的记录 | 标记为异常，不参与预测 |
| 异常值 | 销量 > 3 倍标准差 | 标记为异常，人工复核 |
| 重复数据 | 同一门店+商品+日期 | 保留最新记录 |
| 格式校验 | 日期格式、数值格式 | 自动修正或标记异常 |
| 一致性 | 线上/线下库存不一致 | 以 ERP 数据为准 |

## 3. 数据导入规范

### 3.1 导入功能逻辑（前置校验模式）

**核心原则：前置全量校验，有错不导入，全部通过才入库**

| 阶段 | 处理逻辑 | 用户反馈 |
|-----|---------|---------|
| 文件上传 | 校验文件格式（.xlsx）和大小（≤10MB） | 格式错误时 Toast 提示阻断 |
| 数据校验 | 逐行校验所有数据（必填/格式/长度/唯一性/关联数据/字典值） | 错误列表直接展示在页面（行号+列名+原因） |
| 导入执行 | 仅当全部数据校验通过后才执行导入 | 成功后 Toast 提示导入条数 |

### 3.2 校验类型清单

1. **文件级校验**：格式、大小
2. **必填项校验**：必填字段不能为空
3. **格式校验**：正则匹配（手机号、邮箱、编码等）
4. **长度校验**：字段值长度限制
5. **唯一性校验**：与现有数据对比，关键字段不重复
6. **关联数据校验**：外键/关联字段值在系统中存在
7. **字典值校验**：枚举/字典字段值在有效范围内

### 3.3 错误提示格式

- 统一格式：`第X行，【字段名】：错误原因`
- 示例：`第3行，用户名：不能为空`、`第5行，手机号：格式不正确`

### 3.4 导出文件命名规范

- **格式**: `{业务前缀}_{YYYYMMDD}_{HHMMSS}.xlsx`
- **示例**: `历史销量数据_20260612_103045.xlsx`
- **导入模板**: `批量导入模板.xlsx`（固定名称，不带时间戳）

## 4. 数据模型

### 4.1 数据质量日志表

```sql
CREATE TABLE data_quality_log (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    task_type       VARCHAR(50) COMMENT '任务类型：IMPORT/CLEAN/CHECK',
    source          VARCHAR(200) COMMENT '数据源',
    total_records   INT COMMENT '总记录数',
    success_records INT COMMENT '成功记录数',
    error_records   INT COMMENT '错误记录数',
    error_details   JSON COMMENT '错误详情',
    status          VARCHAR(20) COMMENT 'SUCCESS/PARTIAL/FAILED',
    started_at      DATETIME COMMENT '开始时间',
    completed_at    DATETIME COMMENT '完成时间',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 4.2 基础数据表

**门店表**
| 字段名 | 字段类型 | 说明 |
|--------|----------|------|
| 门店ID | 数字 | 主键 |
| 门店名称 | 文本 | 门店名称 |
| 所属区域 | 文本 | 区域 |
| 商圈类型 | 单选 | 商业/住宅/办公 |
| 状态 | 单选 | 启用/禁用 |

**商品表**
| 字段名 | 字段类型 | 说明 |
|--------|----------|------|
| 商品ID | 数字 | 主键 |
| 商品名称 | 文本 | 商品名称 |
| 品类 | 关联 | 关联品类表 |
| 规格 | 文本 | 规格描述 |
| 配送价 | 数字 | 成本价 |
| 售价 | 数字 | 销售价 |
| 状态 | 单选 | 启用/禁用 |
