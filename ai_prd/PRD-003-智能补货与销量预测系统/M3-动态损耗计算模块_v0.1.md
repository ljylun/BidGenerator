## 1. 模块概述

### 1.1 定位

动态损耗计算模块替代传统固定 3% 损耗估算方式，基于气温、存储时长、品类属性等多维因子动态计算每日损耗率，实现"真实毛利"的自动化核算。

### 1.2 目标

| 指标 | 目标值 |
|------|--------|
| 损耗计算精度 | 偏差 ≤ 0.5% |
| 报损率降低 | 从 8% 降至 4%（降低 50%） |
| 毛利提升 | 真实损耗核算后，毛利率预计提升 2-3 个百分点 |
| 计算时效 | 每日完成全量损耗计算 |

### 1.3 用户角色

| 角色 | 使用场景 | 核心诉求 |
|------|----------|----------|
| 财务人员 | 损耗核算 | 真实、动态的损耗数据 |
| 运营管理层 | 全局库存健康度 | 损耗趋势分析 |

## 3. 损耗模型

### 3.1 损耗率计算公式

```
日损耗率 = 基础损耗率 × K_temp × K_time × K_category

其中：
- 基础损耗率：品类固有属性（如草莓 5%，苹果 1%）
- K_temp = 1 + 0.03 × (实际气温 - 20) / 10
  （气温每升高 10°C，损耗率增加 3%）
- K_time = 1 + 0.05 × (存放时长 - 24) / 24
  （存放每增加 24 小时，损耗率增加 5%）
- K_category：品类修正系数
```

### 3.2 品类损耗参数表

| 品类 | 基础损耗率 | 温度敏感度 | 时间敏感度 | 存储条件 |
|------|-----------|-----------|-----------|----------|
| 草莓 | 5.0% | 高 | 高 | 冷藏 2-4°C |
| 蓝莓 | 4.5% | 高 | 高 | 冷藏 2-4°C |
| 车厘子 | 3.0% | 中 | 高 | 冷藏 2-4°C |
| 西瓜 | 1.5% | 中 | 低 | 常温 |
| 苹果 | 1.0% | 低 | 低 | 冷藏 0-4°C |
| 香蕉 | 3.0% | 高 | 中 | 常温 13-15°C |
| 芒果 | 2.5% | 中 | 中 | 常温 |

### 4.3 核心表结构（关系型数据库方案）

```sql
CREATE TABLE dynamic_loss (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    store_id        BIGINT NOT NULL COMMENT '门店ID',
    product_id      BIGINT NOT NULL COMMENT '商品ID',
    loss_date       DATE NOT NULL COMMENT '损耗日期',
    temperature     DECIMAL(5, 2) COMMENT '当日气温',
    storage_hours   INT COMMENT '存储时长（小时）',
    base_loss_rate  DECIMAL(5, 4) COMMENT '基础损耗率',
    temp_coefficient DECIMAL(5, 4) COMMENT '温度系数',
    time_coefficient DECIMAL(5, 4) COMMENT '时间系数',
    category_coefficient DECIMAL(5, 4) COMMENT '品类系数',
    dynamic_loss_rate DECIMAL(5, 4) COMMENT '动态损耗率',
    loss_amount     DECIMAL(10, 2) COMMENT '损耗金额',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_store_product_date (store_id, product_id, loss_date)
);

CREATE TABLE category_loss_config (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    category_id     BIGINT NOT NULL COMMENT '品类ID',
    category_name   VARCHAR(100) COMMENT '品类名称',
    base_loss_rate  DECIMAL(5, 4) NOT NULL COMMENT '基础损耗率',
    temp_sensitivity VARCHAR(20) COMMENT '温度敏感度：HIGH/MEDIUM/LOW',
    time_sensitivity VARCHAR(20) COMMENT '时间敏感度：HIGH/MEDIUM/LOW',
    storage_condition VARCHAR(50) COMMENT '存储条件',
    optimal_temp_min DECIMAL(5, 2) COMMENT '最适温度下限',
    optimal_temp_max DECIMAL(5, 2) COMMENT '最适温度上限',
    status          TINYINT DEFAULT 1,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## 6. 业务流程

```
实时数据采集
  ├─ 气温数据（实时/预报，来源：气象 API）
  ├─ 商品入库时间（来源：ERP）
  ├─ 商品品类属性（易损度等级）
  └─ 存储条件（冷藏/常温/冷冻）
         │
         ▼
损耗率动态计算
  损耗率 = 基础损耗率 × 温度系数 × 时间系数 × 品类系数
         │
         ▼
库存自动校准
  系统库存 = 账面库存 - 累计动态损耗
         │
         ▼
真实毛利自动核算
  毛利 = 售价 - 配送价 - 动态损耗金额
         │
         ▼
毛利异常告警
  毛利率低于阈值 → 通知财务和运营
```
