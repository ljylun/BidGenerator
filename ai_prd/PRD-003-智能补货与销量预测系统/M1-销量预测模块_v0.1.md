## 1. 模块概述

### 1.1 定位

销量预测模块是智能补货系统的核心引擎，负责基于历史销量、天气、节假日、促销活动等多维因子，利用时序预测模型预测单店单品未来 3-7 天销量。

### 1.2 目标

| 指标 | 目标值 |
|------|--------|
| MAPE（平均绝对百分比误差） | ≤ 25%（加权平均） |
| 覆盖率（可预测 SKU 占比） | ≥ 80% |
| 预测时效 | 每日凌晨 2:00-6:00 完成全量预测 |
| 预测粒度 | 单店单品，未来 3-7 天 |

### 1.3 用户角色

| 角色 | 使用场景 | 核心诉求 |
|------|----------|----------|
| 店长 | 每日订货决策 | 每天早上收到未来 7 天的销量预测 |
| 采购人员 | 批量采购计划 | 查看全国/区域的品类销量预测 |

## 3. 预测结果 Prompt 设计

系统使用以下 Prompt 模板生成预测结果解释：

```
系统提示词：
你是一个零售销量预测解释助手。请用通俗易懂的语言解释以下预测结果：

预测数据：
- 门店：{store_name}
- 商品：{product_name}
- 预测日期：{date}
- 预测销量：{predicted_qty}（置信区间：{lower} - {upper}）

1. 一句话预测结论
2. 关键影响因素说明（最多 3 个）
3. 订货建议及理由

输出格式：
{
  "summary": "...",
  "factors": ["...", "...", "..."],
  "recommendation": {
    "order_qty": ...,
    "reason": "..."
  }
}
```

## 4. 数据模型

### 4.1 门店商品预测表（钉钉AI表格）

| 字段名 | 字段类型 | 说明 |
|--------|----------|------|
| 门店 | 关联 | 关联门店表 |
| 商品 | 关联 | 关联商品表 |
| 预测日期 | 日期 | 预测日期 |
| 预测销量 | 数字 | 预测销量 |
| 置信区间下限 | 数字 | 下限值 |
| 置信区间上限 | 数字 | 上限值 |
| 置信水平 | 数字 | 默认80% |
| 模型版本 | 文本 | 模型版本号 |
| 影响因子 | 多行文本 | JSON格式 |
| 实际销量 | 数字 | 回填 |
| 预测误差率 | 数字 | 计算值 |
| 创建时间 | 系统字段 | 自动记录 |

### 4.2 核心表结构（关系型数据库方案）

```sql
CREATE TABLE demand_forecast (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    store_id        BIGINT NOT NULL COMMENT '门店ID',
    product_id      BIGINT NOT NULL COMMENT '商品ID',
    forecast_date   DATE NOT NULL COMMENT '预测日期',
    forecast_qty    DECIMAL(10, 2) NOT NULL COMMENT '预测销量',
    lower_bound     DECIMAL(10, 2) COMMENT '置信区间下限',
    upper_bound     DECIMAL(10, 2) COMMENT '置信区间上限',
    confidence_level DECIMAL(5, 2) DEFAULT 80 COMMENT '置信水平',
    model_version   VARCHAR(50) COMMENT '模型版本',
    factors         JSON COMMENT '影响因子及权重',
    actual_qty      DECIMAL(10, 2) COMMENT '实际销量（回填）',
    error_rate      DECIMAL(5, 4) COMMENT '预测误差率',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_store_product_date (store_id, product_id, forecast_date)
);
```

## 6. 技术方案

### 6.1 模型选择

| 组件 | 技术方案 | 说明 |
|------|----------|------|
| 基线模型 | Prophet | 适合有季节性数据 |
| 进阶模型 | LSTM | 适合复杂非线性，品类差异化 |

### 6.2 容错机制

- 模型异常时降级至移动平均法
- 预测结果缓存至 Redis，保证可用性
