## 1. 产品概述

### 1.1 背景与问题

| 维度 | 现状 |
|------|------|
| **痛点来源** | 运营部、市场部 |
| **当前方式** | 运营人员手动添加好友、手动群发消息、手动打标签、手动回复 |
| **核心问题** | 人工效率低、容易出错、无法规模化、运营策略执行不一致 |
| **业务影响** | 私域用户增长缓慢、活跃度低、转化率差 |
| **量化损失** | 运营人员 70% 时间花在重复性操作上；私域转化率仅 2%（行业优秀值 5%） |

### 1.2 产品定义

**一句话描述**：通过 RPA（机器人流程自动化）技术，自动化执行私域运营中的重复性操作（好友添加、消息推送、标签管理、数据统计），释放运营人员精力用于策略优化。

**产品愿景**：构建自动化私域运营体系，将运营人员从重复劳动中解放，实现"千人千面"的精准运营。

**产品载体**：本产品为运行在钉钉平台上的**钉钉AI表格应用**，利用钉钉AI表格的多维表格能力、自动化流程、AI字段识别、权限管理等原生功能，实现私域运营数据的采集、存储、分析与协作。

### 1.3 目标用户

| 角色 | 用户画像 | 使用场景 | 核心诉求 | 使用频率 |
|------|----------|----------|----------|----------|
| 私域运营 | 25-35 岁，用户运营 | 日常私域运营 | 自动化重复操作 | 每日 |
| 市场人员 | 28-40 岁，营销策划 | 活动策划执行 | 精准触达用户 | 每周 |
| 运营管理层 | 35-50 岁，团队管理 | 效果分析 | 运营数据看板 | 每周 |

## 2. 业务流程

### 2.1 自动化加好友流程

```
导入手机号列表（Excel/CRM）
        │
        ▼
RPA 自动执行
  ├─ 打开微信/企微
  ├─ 逐个添加好友
  ├─ 发送欢迎语
  └─ 自动打标签
        │
        ▼
结果记录（钉钉AI表格）
  ├─ 成功/失败统计
  ├─ 失败原因分析
  └─ 重试机制
        │
        ▼
运营人员查看报表
```

### 2.2 自动化营销推送流程

```
创建营销活动
  ├─ 选择目标人群（标签筛选）
  ├─ 编辑推送内容
  └─ 设置推送时间
        │
        ▼
RPA 自动执行
  ├─ 按人群分组
  ├─ 定时发送消息
  └─ 个性化内容替换
        │
        ▼
效果追踪
  ├─ 发送成功率
  ├─ 打开率
  └─ 转化率
        │
        ▼
数据写入钉钉AI表格 → 生成报表
```

#### 核心表结构（备用关系型数据库方案）

```sql
-- 用户列表
CREATE TABLE private_user (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_no         VARCHAR(50) UNIQUE NOT NULL COMMENT '用户编号',
    user_name       VARCHAR(100) COMMENT '用户昵称',
    phone           VARCHAR(20) COMMENT '手机号',
    source          VARCHAR(50) COMMENT '添加来源',
    tags            JSON COMMENT '用户标签',
    add_date        DATE COMMENT '添加日期',
    status          VARCHAR(20) DEFAULT 'ACTIVE' COMMENT 'ACTIVE/LOST/UNSUBSCRIBED',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_phone (phone),
    INDEX idx_tags (tags)
);

-- 营销活动表
CREATE TABLE marketing_campaign (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    campaign_no     VARCHAR(50) UNIQUE NOT NULL COMMENT '活动编号',
    campaign_name   VARCHAR(200) NOT NULL COMMENT '活动名称',
    target_tags     JSON COMMENT '目标人群标签',
    content         TEXT COMMENT '消息内容',
    variables       JSON COMMENT '变量配置',
    scheduled_time  DATETIME COMMENT '计划推送时间',
    actual_time     DATETIME COMMENT '实际推送时间',
    status          VARCHAR(20) DEFAULT 'DRAFT' COMMENT 'DRAFT/PENDING/RUNNING/COMPLETED',
    creator         VARCHAR(50) COMMENT '创建人',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 发送记录表
CREATE TABLE send_record (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    campaign_id     BIGINT NOT NULL COMMENT '活动ID',
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    send_time       DATETIME COMMENT '发送时间',
    send_status     VARCHAR(20) COMMENT 'SUCCESS/FAILED',
    fail_reason     TEXT COMMENT '失败原因',
    opened          TINYINT DEFAULT 0 COMMENT '是否打开',
    converted       TINYINT DEFAULT 0 COMMENT '是否转化',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_campaign (campaign_id),
    INDEX idx_user (user_id)
);

-- 话术模板表
CREATE TABLE message_template (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    template_name   VARCHAR(200) NOT NULL COMMENT '模板名称',
    template_type   VARCHAR(50) COMMENT 'WELCOME/PROMOTION/CARE/OTHER',
    content         TEXT COMMENT '模板内容',
    variables       JSON COMMENT '变量列表',
    status          TINYINT DEFAULT 1,
    creator         VARCHAR(50) COMMENT '创建人',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 4.3 API 规格

#### 好友添加 API

```
POST /api/v1/rpa/friend/add
Content-Type: application/json

请求参数：
{
  "phones": ["13800138001", "13800138002"],
  "welcome_msg": "您好，我是XX水果店的客服，欢迎关注我们！",
  "tags": ["新客", "活动引流"]
}

响应：
{
  "code": 200,
  "data": {
    "task_id": "task001",
    "total": 2,
    "estimated_time": "2分钟",
    "message": "已创建添加任务"
  }
}
```

#### 创建营销活动 API

```
POST /api/v1/rpa/campaign/create
Content-Type: application/json

请求参数：
{
  "campaign_name": "周末促销活动",
  "target_tags": ["活跃用户", "成都区域"],
  "content": "亲爱的{name}，本周末全场水果8折，快来选购！",
  "scheduled_time": "2026-06-14 10:00:00"
}

响应：
{
  "code": 200,
  "data": {
    "campaign_no": "C20260612001",
    "status": "DRAFT",
    "message": "活动已创建"
  }
}
```

```
POST /api/v1/rpa/campaign/execute
```

### 4.4 钉钉AI表格集成方案

#### 4.4.1 钉钉AI表格应用架构

本产品作为钉钉AI表格应用运行，利用钉钉开放平台提供的以下核心能力：

| 能力模块 | 用途 | 实现方式 |
|----------|------|----------|
| 多维表格 | 数据存储与管理 | 使用钉钉AI表格作为主数据存储 |
| 自动化流程 | 业务逻辑触发 | 配置自动化规则，实现任务调度 |
| 权限管理 | 数据访问控制 | 配置表格级、行级、列级权限 |
| 消息通知 | 推送提醒 | 通过钉钉机器人推送任务状态 |
| 连接器 | 外部系统集成 | 通过连接器调用 RPA 服务 |

#### 4.4.2 钉钉开放平台集成

**钉钉应用配置**：
- 应用类型：企业内部应用
- 运行平台：钉钉AI表格
- 权限范围：
  - `dingtalk:app:table:read` - 表格读取
  - `dingtalk:app:table:write` - 表格写入
  - `dingtalk:user:readonly` - 用户基本信息读取
  - `dingtalk:message:send_as_bot` - 消息发送

#### 4.4.3 前端技术适配

**运行环境要求**：
- 运行平台：钉钉客户端（iOS/Android）内置浏览器
- 技术框架：钉钉AI表格小程序框架（基于钉钉小程序技术栈）
- 兼容性要求：
  - iOS 13.0+
  - Android 8.0+
  - 钉钉客户端版本 6.5.0+
