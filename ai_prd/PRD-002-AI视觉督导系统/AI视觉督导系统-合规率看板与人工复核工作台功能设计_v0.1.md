## 一、功能角色矩阵说明

### 1.1 功能描述

- **功能名称：** 合规率看板与人工复核工作台
- **所属模块：** AI视觉督导系统
- **功能描述：** 提供门店/区域/全国维度的合规率统计看板，支持督导对AI审核边界案例进行人工复核，并通过收集复核结果持续优化AI审核能力。

### 1.2 角色权限总览

| 角色      | 功能权限                        | 数据权限   |
| ------- | --------------------------- | ------ |
| 运营管理层 | 查看看板、查看趋势、导出报告、查看排名     | 全量数据   |
| 督导人员 | 查看看板、人工复核、查看复核记录         | 全量数据   |
| 商学院 | 查看看板、导出培训报告              | 全量数据 |
| 店长 | 查看本店合规趋势                   | 仅本店数据 |

### 1.3 功能角色矩阵

| 功能点  | 运营管理层 | 督导人员 | 商学院 | 店长 |
| ---- | :-----: | :-----: | :-----: | :-----: |
| 查看全国看板 |    是    |    是    |    是    |    否    |
| 查看区域看板 |    是    |    是    |    是    |    否    |
| 查看本店合规 |    是    |    是    |    是    |    是    |
| 人工复核 |    否    |    是    |    否    |    否    |
| 导出报告 |    是    |    否    |    是    |    否    |

## 三、状态流转与流程图

### 3.1 合规率统计流程

```mermaid
flowchart TD
    A[审核任务完成] --> B[更新合规率统计表]
    B --> C[按门店/区域/全国汇总]
    C --> D[计算各维度合规率]
    D --> E[更新看板数据]
    E --> F{异常检测}
    F -->|合规率下降≥10%| G[触发告警通知]
    F -->|正常| H[继续监控]
```

### 3.2 人工复核流程

```mermaid
flowchart TD
    A[AI审核结果标记为边界案例] --> B[进入人工复核队列]
    B --> C[督导查看待复核列表]
    C --> D[督导进行人工复核]
    D --> E{复核结果}
    E -->|与AI一致| F[确认AI结果]
    E -->|与AI不一致| G[修正结果 + 标记为优化样本]
    F --> H[复核完成]
    G --> H
    H --> I[复核结果纳入能力进化数据集]
```

## 八、特殊说明

### 8.1 合规率计算规则

- 合规率 = 通过审核任务数 / 总审核任务数 × 100%
- 统计维度：按门店/区域/全国，按日/周/月
- 异常告警：合规率较上期下降 ≥ 10% 时触发告警通知

### 8.2 能力进化机制

- 人工复核结果与AI结果不一致的样本自动纳入优化数据集
- 每月汇总优化样本，更新Prompt模板
- 能力进化效果跟踪：每月AI识别精度提升3-5%

### 8.3 其他特殊规则

1. 看板数据每日凌晨自动更新，支持手动刷新
2. 区域排名按合规率降序排列，相同合规率按审核数降序
3. 问题分布统计周期与看板筛选时间范围一致
