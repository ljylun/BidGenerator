# 墨丁怪诞正文配图（传统文化手稿风格）

## 核心定位

为中文文章设计和生成 16:9 横版正文配图。目标不是商业中国风插画、国潮海报或国学课件，而是把文章里的关键判断、流程、结构、状态或隐喻，变成一张素宣上随手勾出的工作草稿——拙而准确，荒诞但成立。

默认视觉 IP 是“墨丁”：一块墨块或墨迹形状的黑色实心小怪物，白点眼，枯笔飞白肢体，安静、木讷且认真。墨丁必须承担画面的核心体力活，不能站在旁边当文化符号。

## 先读这些参考

按任务需要读取，不要一次塞满上下文：

- `references/style-dna.md`：墨丁风格 DNA、素宣白底、枯笔线条、朱砂花青赭石三色用法、字体与禁忌。
- `references/moding-ip.md`：墨丁 IP 的形象、性格、动作库和禁止项。
- `references/composition-patterns.md`：构图类型、原创隐喻生成三步法、可用物件池与反复刻规则。
- `references/prompt-template.md`：单张生图提示词模板。
- `references/qa-checklist.md`：墨丁生成后检查与迭代规则。
- `assets/examples/`：仅作低频视觉校准（枯笔密度、留白尺度、朱墨比例），不进入默认生成路径。不要照抄这些案例的构图、物件或标注。

## 工作流

### 1. 消化正文

先读用户给的正文、链接、Notion 页面、Markdown 文件或截图。提炼：

- 核心观点是什么
- 哪些段落承担认知转折
- 哪些内容适合用图解释（例如：校勘闭环、典故分拣、散佚与辑佚、前后对比、知识沉淀、常见校书坑、状态变化）
- 哪些地方只适合文字，不需要图

不要平均配图。优先选择“认知锚点”，把抽象概念换成一个具体、可操作的传统文化体力活。

### 2. 先出配图策略

如果用户只是说“分析怎么配图 / 思考哪些地方需要配图”，先给 shot list。每张图写清楚：

- 放在哪个段落后
- 图的主题
- 核心意思
- 结构类型（Workflow/系统局部/前后对比/角色状态/概念隐喻/方法分层/地图路线/小漫画分镜）
- 墨丁在图里做什么（具体的笨拙动作）
- 建议元素（1-2 个传统物件，如装订线、蛀洞、洗笔缸、浆糊碗、残碑拓片）
- 建议中文标注词（2-6 字，短而可读）

默认 4-6 张。文章很短时 1-3 张；长文也不要轻易超过 8 张。够用就好，避免把正文做成册页展。

### 3. 单张生成

如果用户明确要求“生成 / 输出 / 做图 / 帮我生成”，不要停下来等确认；用内置 `image_gen` 每张单独生成。不要把多张图拼在一张里。

每张图只讲一个核心结构。提示词必须包含：

- 16:9 横版中文正文配图
- 纯白背景（素宣感，可有一两处极淡偶然墨点，但无纹理贴图）
- 黑色手绘枯笔线条，有飞白、断续
- 少量朱砂红（圈点/批注/警告）、花青蓝（天头地脚小注）、赭石色（主路径线或穿书线）手写批注
- 大量留白，主体占画面 40%-50%
- 墨丁作为核心动作主体，表情木讷、认真
- 禁止商业中国风、国潮、工笔渲染、装饰性文物堆砌
- 禁止左上角类型标题
- 不要复刻过往案例。每次从当前文章重新发明一个奇怪但成立的隐喻（如：用洗笔水缸过滤信息、用装订线穿错孔表示路径断裂、用填蛀洞修复知识断层）

### 4. 检查与迭代

生成后检查 `references/qa-checklist.md`。如果出现以下问题，优先重生成或局部编辑：

- 墨丁只是装饰，没有动手干活
- 画面太满、元素太杂
- 太像国学课程封面、文创产品图或正式流程图
- 中文标注太多或错字严重
- 左上角出现“校勘流程/典故系统/知识体系图”等标题
- 画风太雅、太可爱、太精致
- 背景不是干净白底（出现米黄纸纹、做旧效果等）
