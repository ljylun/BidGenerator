# QA Checklist

## 必过项

- 是 16:9 横版。
- 背景是干净白底。
- 有剪报（泛黄旧纸碎片、毛边、复古印刷网点等剪报特征）。
- 有剪报角色——它承担核心动作，不只是装饰。
- 没有复刻旧案例构图，而是为当前文章生成了新的拼贴隐喻。
- 画面怪诞、有创意、有意思，有"手工构建系统"的质感。
- 简洁清爽，主体不超过画面约 60%。
- 一张图只讲一个核心结构。
- 中文标注少、短、能读，像档案管理员的墨水批注。
- 橙 / 棕黄只用于主路径或箭头（复古暖色调）。
- 红色只用于重点、问题、提醒或结果（像红墨水或印章）。
- 蓝色只用于补充说明、反馈或系统状态（像旧蓝墨水或档案标签）。
- 有手工拼贴的错位感、胶带痕迹、元素之间的叠层关系。
- 有明确的剪报质感：毛边、白边、不同来源的旧纸混搭。

## 失败信号

出现以下情况，重生成或局部编辑：

- 左上角有"常见坑 / Workflow / 系统架构图 / 路线图"等标题。
- 剪报像吉祥物、表情包或可爱卡通。
- 画面像 PPT、课程课件、正式流程图。
- 元素太多、箭头太多、节点太多。
- 文字变成大段解释。
- 背景有纸纹、阴影、渐变、米色、噪点。
- 真实 UI 截图或科技感界面。
- 中文错字严重或标注不可读。
- 画面太死板，没有荒诞隐喻。
- 和 `assets/examples/` 里的旧案例构图过于相似。
- 剪报只是贴在角落里的复古氛围贴纸，没有参与信息处理。
- 画面太干净、太数字化，失去了手工拼贴的笨拙感。
- 所有元素用同一种纸感，没有混搭不同来源的旧纸质感。
- 剪报看起来像精致的现代矢量插画，而不是从旧报纸上粗糙剪下的。

## 迭代方法

- 太普通：让剪报成为动作主体，加入一个奇怪但成立的拼贴隐喻。
- 太复杂：删节点，只保留一个动作和 3-5 个短标注。
- 太可爱：强调 deadpan、blank serious expression、not cute、not mascot。
- 太 PPT：去掉标题、边框、整齐网格和过多箭头，改成手工拼贴场景。
- 太像旧案例：保留核心意思，换掉主物件和剪报动作。
- 文字错：优先局部编辑；错得多就重生成并减少标注数量。
- 太干净：加入更多剪报毛边、纸感混搭、手工胶带痕迹。
- 剪报没参与动作：让剪报正在执行归档、连接、分拣、盖章等核心动作，而不是旁边站着。

## 交付判断

高质量图应该让读者先觉得"有点怪"，然后 1 秒内看懂结构。画面应该有手工建档的质感——像是有人真的用旧报纸和胶带在白纸上搭建出了一个解释系统。

如果第一眼像教程页或精致海报，而不是白纸上的怪诞拼贴草图，就不合格。

如果去掉剪报，图就失去了"手工构建系统"的隐喻和质感，说明它成功了；如果它只是个好看的复古装饰物，没有参与信息处理，说明太装饰了，需重写提示词。
