# 风格 DNA

## 一句话

纯白底、极简几何、严肃构成感、无表情无装饰。像一位严谨的建筑师或逻辑学家，用高饱和纯色块在白纸上搭建出支撑逻辑的结构——而「大袖」是用服饰的物理特性（甩、卷、抛、藏）缝补这些结构间的连接与过渡的东方苦力。

## 必须

- 16:9 横版正文配图。
- 纯白背景：不要米色、暖灰、渐变、阴影、噪点。
- 无纹理、无渐变、无柔和光影（或仅有极硬的平面投影）。边缘绝对锐利，轮廓清晰。
- 高饱和度单一纯色块：克莱因蓝、国际红、明黄等。
- 大量留白：主体占画面约 40%-60%，至少 35% 空白，最好有一整块安静区域。
- 少量中文手写批注：最多 5-8 处，每处尽量 2-8 个字，像建筑师在蓝图上的标注。
- 一张图只讲一个核心动作、结构、状态或隐喻。
- 结构要自然表达，不要在图上写结构类型名称。

## 「大袖」IP 核心要求

- 「大袖」是画面的核心参与者和逻辑连接者，不是一般装饰元素。
- 极简几何结构：由两到三个极为流畅、边缘锐利（或极具毛笔顿挫感）的色块组成。最核心的视觉符号是**两只夸张、宽大、垂坠的交领大袖**。
- 无面人：没有五官、没有发型。头部只是一个简单的留白圆圈，或一个极简的斗笠剪影。
- 色彩克制：整体采用高纯度的中国传统色单色（如朱砂红、曜石黑、石绿），与现代黑白图表形成强烈视觉反差。
- 线条质感：衣服的轮廓具有强烈的东方白描或书法飞白质感，有风骨，不圆润。
- 「大袖」必须用袖子或衣襟**参与构图**——甩、卷、抛、藏、撑、扫、劈——承担核心逻辑动作。
- 性格：大智若愚、道法自然、以柔克刚。清冷、幽默、不卖萌，有一种"无能为力但依然在维持秩序"的荒诞感。

## 颜色

- 黑色 / 深灰：结构线稿、框线、主要文字标注。
- 橙 / 棕黄：主流程、路径、箭头、从 A 到 B 的流向关系。
- 红色：重点批注、问题、情绪点、关键提醒、结果。像红色印章或红笔圈出。
- 蓝色：补充说明、脑内状态、系统状态、第二层解释、AI/assistant/自动化提示。
- 「大袖」本体的颜色：高纯度中国传统色单色（朱砂红、曜石黑、石绿等），与画面其他元素形成反差。

颜色要克制，宁可少不要多。整体色调以纯色块的色相为主，不要渐变过渡。

## 绝对不要

- 不要商业插画、精致矢量图、扁平设计。
- 不要 PPT 信息图、正式流程图、课程课件。
- 不要可爱卡通海报、儿童插画、科技感 UI、真实 App 截图。
- 不要现代渐变、复杂背景、均匀噪点。
- 不要把每个节点都解释清楚。
- 不要在左上角写"Workflow 流程图 / 系统架构图 / 常见坑 / 路线图"等类型标题。
- 不要使用低饱和度或过多颜色混杂。
- 不要让画面太数字化、太花哨——要有严肃的构成感。
- 不要给「大袖」添加五官、表情、发型或任何拟人化特征。
- 不要画复杂的汉服绣花、配饰（玉佩、发簪、流苏）、褶皱。
- 不要画成大眼睛 Q 版古风娃娃，不要有任何二次元或萌系表情。
- 不要让「大袖」只是穿着汉服抱剑靠在方框旁边看——必须用袖子或衣襟参与构图。
- 不要堆砌祥云、灯笼、折扇等符号——「大袖」本身就是唯一的中国元素。
- 不要让袖子看起来柔软无骨——要有风骨，有毛笔顿挫感。

## 审美方向

要严谨、克制、精准、有构成感。要有"用基础几何单元搭建复杂逻辑"的建筑学美感。「大袖」是"逻辑缝纫师与承重立柱"——去掉它，图表里那些飘逸、流动的中式线条逻辑（如弧形连线、留白过渡）会瞬间塌陷，变成一张毫无美感的普通表格。

不要可爱、幼稚、很复杂、死板。不要精致的现代感。不要花哨装饰。
