# 风格 DNA

## 一句话

纯白底、剪报拼贴、复古荒诞、手绘毛边、留白克制、怪诞产品草图感。像一位老派档案管理员，用旧报纸和胶带在白纸上手工搭建出一个解释系统。

## 必须

- 16:9 横版正文配图。
- 纯白背景：不要米色、暖灰、渐变、阴影、噪点。
- 剪报拼贴风格：所有元素看起来像从旧报纸、旧杂志上剪下来的，边缘带有明显的剪刀裁剪毛边和白色留白。
- 泛黄的纸张纹理，或黑白/低饱和度的复古印刷网点。
- 大量留白：主体占画面约 40%-60%，至少 35% 空白，最好有一整块安静区域。
- 少量中文手写批注：最多 5-8 处，每处尽量 2-8 个字，像档案管理员的墨水标注。
- 一张图只讲一个核心动作、结构、状态或隐喻。
- 结构要自然表达，不要在图上写结构类型名称。

## 颜色

- 黑色 / 深灰：剪报主体线稿、框线、结构、主要文字、复古印刷文字块。
- 橙 / 棕黄（复古暖色）：主流程、路径、箭头、自动化流向、从 A 到 B 的移动关系。泛黄旧纸本身的色调可归此类。
- 红色：重点批注、问题、情绪点、关键提醒、结果。像红色印章或红墨水圈出。
- 蓝色：补充说明、脑内状态、系统状态、第二层解释、AI/assistant/自动化提示。像旧蓝墨水或蓝色档案标签。

颜色要克制，宁可少不要多。整体色调偏复古、低饱和。

## 剪报质感要求

- 每个物件看起来是从旧纸源剪下的独立碎片：边缘不规则、有微小毛边、有纸张白边。
- 元素之间用「视觉胶带」或叠层关系连接，保持手工拼贴的错位感。
- 可以出现：旧打字机字母、老式齿轮剪影、邮戳、档案袋标签、旧照片局部、粗糙手绘图形等复古元素。
- 不要所有元素都用同一种质感——混搭不同来源的旧纸感更有手工建档的味道。

## 绝对不要

- 不要商业插画、精致矢量图、扁平设计。
- 不要 PPT 信息图、正式流程图、课程课件。
- 不要可爱卡通海报、儿童插画、科技感 UI、真实 App 截图。
- 不要现代渐变、复杂背景、均匀噪点。
- 不要把每个节点都解释清楚。
- 不要在左上角写"Workflow 流程图 / 系统架构图 / 常见坑 / 路线图"等类型标题。
- 不要使用鲜艳的高饱和度色彩。
- 不要让画面太数字化、太干净——要有手工时代的笨拙感。

## 审美方向

要怪诞、创意、有意思、简洁清爽、天马行空。要有"用原始工具解决复杂问题"的荒诞感。

不要可爱、幼稚、很复杂、死板。不要精致的现代感。
