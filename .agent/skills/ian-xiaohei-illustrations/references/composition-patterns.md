# 构图模式与原创规则

## 基础结构类型

选择一种结构即可，不要混太多。

### Workflow 流程

适合：输入 -> 处理 -> 输出，内容生产，AI 工作流，自动化链路。

画法：左侧输入（几何体代表素材），中间「大袖」用袖子结构处理，右侧输出，橙色复古箭头表达主流向。「大袖」正在用服饰的物理方式推动流程——比如长袖甩出跨越半个屏幕连接输入与处理模块、袖口张开像漏斗一样收纳待处理物料、裙摆旋转甩出弧线导向输出方向。

### 系统局部

适合：信息来源、过滤器、数据库、渲染器、agent 系统局部。

画法：只画 3-5 个核心模块（像不同颜色的几何体排列），「大袖」参与其中一个关键动作——比如双袖下垂作揖如同两根立柱撑住上方沉重的核心模块、一只袖口张开像黑洞一样把杂乱的底层数据往袖子里扫、身体旋转用袖子甩出弧线连接两个模块。

### 前后对比

适合：混乱/有序，手动/自动，分散/收拢，焦虑/稳定。

画法：左混乱（几何体散落、倾斜、堆叠无序），右稳定（整齐排列、水平堆叠、结构稳固），中间橙色箭头。「大袖」从左到右移动，执行整理动作——比如用袖子把歪斜的方块扶正铺平、用衣襟把散落的球体排列成行、用裙摆旋转把混乱的线团收拢成整齐的圆柱。

### 角色状态

适合：用户痛点、创作者状态、工具太多、信息焦虑、卡住到跑起来。

画法：2-4 个小状态，每个状态一个短标注，像蓝图上的标记点。「大袖」在每个状态有不同的服饰姿态——卡住时用一只袖子捂住大半个身子只露出一只脚卡在断点里、跑起来时袖子向后飞扬延伸出路径、稳定时双袖下垂双手作揖安然站立。

### 概念隐喻

适合：内容工厂、信息仓库、脑内黑盒、工作流机器、自动日报。

画法：一个大的结构体或机器（由几何体拼合而成），少量输入，一个输出。「大袖」在结构中执行某个关键服饰动作。要有记忆点——这台机器看起来荒诞但逻辑成立，由纯粹的几何关系和「大袖」的服饰形变构成。

### 方法分层

适合：方法论框架、系统层级、能力栈、内容系统分层。

画法：一层层像方块叠放或圆柱嵌套，不要正式金字塔；「大袖」在旁边支撑或搭建——比如双袖逐层往上堆叠表达递进、衣襟被挤压成楔子卡住关键层级、袖子延伸在层级间连接传递。

### 地图路线

适合：从想法到上线、用户路径、内容承接路径、学习路线。

画法：一条弯曲路径（像蓝图上的手绘路线），少量节点，「大袖」沿路径移动或定位——比如袖子沿路径延伸铺出轨道、在关键节点双袖张开成地标、衣襟被挤压成楔子标记转折点。

### 小漫画分镜

适合：失败到成功、真实过程、吐槽、使用前后变化。

画法：2-4 个小场景，每格只表达一个动作。像建筑连环画的分镜，「大袖」在每格执行不同的核心服饰结构动作。

## 原创隐喻生成法

每次都从当前文章重新发明隐喻，不能照搬旧图。

### 三步

1. 把抽象概念换成一个服饰动作：长袖甩出连接、袖口张收纳、裙摆旋转导向、双袖下垂承重、衣襟劈开划分、袖子捂身表示断点。
2. 把系统结构换成一个低科技物件：坏掉的机器、纸箱、抽屉、水管、邮筒、怪表盘、秤、井、梯子、奇怪工位。
3. 让「大袖」承担服饰动作：不是站旁边，而是用袖子在机器底部做承重、用衣襟在管道里做连接、用袖子延伸铺路、用袖口包裹杂物消化吸收。动作要服务核心意思，不要为了怪而怪。

### 可用物件池

- 纸箱、抽屉、旧机器、漏斗、秤、邮筒、门、井、梯子、水管、线团、闸门、转盘、黑盒、打孔器、压面机、晾衣绳、怪工位。
- 用时只选 1-2 个，不要堆满。物件本身也应由几何体拼合而成——用纯色块搭建出粗糙的结构感。

### 「大袖」服饰动作池

- 长袖善舞（甩出长袖跨越连接两个模块）
- 袖里乾坤（袖口张开收纳/容纳杂物）
- 顺水推舟（身体旋转，裙摆甩出弧线引导方向）
- 垂衣拱手（双袖下垂作揖，承重支撑）
- 掩面反思（袖子捂身，表示断点/测试中）
- 披荆斩棘（衣襟如裁刀，劈开混沌划分边界）
- 动作要服务核心意思，不要为了怪而怪。

## 反复刻规则

不要默认打开或复刻 `assets/examples/`。这些图片只用于风格校准，例如几何体密度、留白、颜色克制、构成感。

除非用户明确说"照这张 / 复刻这个构图 / 用这个案例改"，否则不要直接复用这些旧构图：

- 「大袖」甩袖连接两个断点模块
- 「大袖」在内容机器里被挤压判断
- 「大袖」用袖口分拣流量/信任/转化
- 「大袖」用袖子包裹素材消化吸收
- 「大袖」延伸袖子牵承接路径
- 「大袖」铺底拉三层信息源
- 三个「大袖」分别延伸/铺底/穿过
- 「大袖」盖章话术工具箱
- 「大袖」举牌看常见坑路径

同类主题也要换新隐喻。例如"承接路径"不一定画路线，可以画「大袖」把袖子延伸到门把手；"一鱼多吃"不一定画鱼，可以画「大袖」被挤压成几种不同形态。
