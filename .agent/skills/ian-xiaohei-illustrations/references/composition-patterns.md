# 墨丁构图模式与原创规则

## 基础结构类型

选择一种结构即可，不要混太多。

### Workflow 流程

适合：输入 → 处理 → 输出，内容生产，知识整理，典故提取与重组。

画法：左侧输入散落的典故残片、未整理的书页或混沌的信息；中间墨丁用装订线、拓印或浆糊进行处理；右侧输出成册的书页、拓片或誊清的定稿。赭石色主流向线表达路径（可用一根穿书的线代替箭头）。

### 系统局部

适合：典故库、校勘台、雕版工位、信息过滤筛、收书阁等局部系统。

画法：只画 3–5 个核心模块，例如“未校稿堆”、“校书案”、“蛀洞修复台”，墨丁在其中一个节点执行关键动作（如朱笔圈错、填补蛀洞），其余节点仅以线稿示意。

### 前后对比

适合：散乱/成册，草稿/定本，口传讹误/定本正声，记忆模糊/记录清晰。

画法：左半为混乱状态（揉皱的字纸、歪斜的批注、水渍漫漶的墨迹），右半为稳定状态（整齐的书页、端正的刻本），中间赭石色转化箭头或一根拉直的装订线。墨丁可以在左侧抓着一把乱线，右侧按住已订好的书册。

### 角色状态

适合：古籍工作者的不同工序状态，知识整理的痛点，从失散到找回的过程。

画法：2–4 个墨丁小状态，每个一个短标注。例如：“捞字”（从洗笔水缸里捞还没化完的字）、“补蛀”（用纸浆填蛀洞）、“对校”（两本异本并排，墨丁在中间比照）、“压平”（墨丁整个人趴在翘起的书页上）。

### 概念隐喻

适合：文化黑盒、典故发酵缸、知识沉淀池、校书机器、信息装订厂。

画法：一个大的怪物件或低科技装置，少量输入，一个输出。例如一口巨大的“校书缸”，残稿从上方投入，墨丁在缸内搅动，缸底流出定本。要有记忆点。

### 方法分层

适合：知识体系分层、典籍分类法、内容系统层级、读书次第。

画法：一层层套叠的函套、书匣或书箱，不要正式金字塔。墨丁在旁边搬动其中一层，或蹲在其中一层里贴标签、塞书页。层次宜拙，不可过于整齐。

### 地图路线

适合：从口传到成书，从散佚到辑佚，从疑问到定论，读书路径。

画法：一条弯曲的装订线或一条墨迹蜿蜒的路线，串联 3–5 个节点。墨丁牵着线头走路，或在某个节点卡住、查看。不用正式路线图，宁可是“纸上散步”。

### 小漫画分镜

适合：校书过程中的意外、典故误用的荒诞现场、修复前后的对比趣事。

画法：2–4 格手绘小场景，每格只表达一个动作。例如：第一格墨丁发现断简，第二格用浆糊小心粘合，第三格盖章“已校”，第四格发现盖反了。

## 原创隐喻生成法

每次都从当前文章重新发明隐喻，不能照搬旧图。

### 三步

1. **把抽象概念换成一个物理动作**：断裂、漏掉、沉淀、散佚、对不上、化开、粘连、填补、归位、拎起、压平、筛出。
2. **把系统结构换成一个低科技传统文化物件**：线装书散页、装订线、蛀洞、洗笔水缸、拓碑棕刷、浆糊碗、旧书箱、字纸篓、雕版上的错误笔画、打湿粘连的稿纸。
3. **让墨丁承担动作**：不是站旁边，而是卡在书页之间、把断线重新穿错孔、用身体压住翘起的书角、从水缸里捞字、用朱笔把错误圈成一个牢笼、把自己当做补纸填入蛀洞。

### 可用物件池

- 散页、装订线、蛀洞、浆糊碗、棕刷、拓包、字纸篓、洗笔缸、书函、雕版、木活字、印章、印泥、镇尺、晾纸绳、断墨、旧笔、残碑、拓片、书箱、函套。
- 每次只选 1–2 个，不要堆砌。

### 墨丁动作池

- 研、磨、拓、裱、校、印、补、捞、引（线）、穿、圈、批、筛、晾、压、扫、填、盖（印）、揭（纸）。
- 动作要服务核心意思，笨拙而认真，不要为了怪而怪。

## 反复刻规则

不要默认复刻任何既有的墨丁构图案例。所有旧图仅用于风格校准（线条的枯润、留白比例、朱墨蓝三色的克制用法）。

除非用户明确要求“照这张改”，否则以下典型构图也须换新隐喻：

- 墨丁在传送带上修补断裂的竹简
- 墨丁在巨大砚台里游泳捞字
- 墨丁变成线装书的装订线
- 墨丁切“典故鱼”
- 墨丁牵一条穿过多个函套的路线
- 墨丁盖章盖出一整面红印
- 墨丁举“常见校勘坑”的告示牌
- 墨丁用漏斗分拣典故

同类主题也要换新隐喻。例如“信息过滤”不一定要画筛子，可以画墨丁把书页浸入洗笔水缸，看哪些字浮起来；“承接路径”不一定要画路线，可以画墨丁把前朝的断简残篇的切口对准，用一根新线对穿不上的孔。
