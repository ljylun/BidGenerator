# 构图模式与原创规则

## 基础结构类型

选择一种结构即可，不要混太多。

### Workflow 流程

适合：输入 -> 处理 -> 输出，内容生产，AI 工作流，自动化链路。

画法：左侧输入（旧报纸剪下的素材），中间剪报或怪机器处理，右侧输出，橙色复古箭头表达主流向。剪报正在用手工方式推动流程——比如推着档案车运送素材、用胶带粘贴传递线。

### 系统局部

适合：信息来源、过滤器、数据库、渲染器、agent 系统局部。

画法：只画 3-5 个核心模块（像从不同杂志剪下的碎片拼在一起），剪报参与其中一个关键动作——比如用放大镜审视某个模块、用订书机把它们钉在一起。

### 前后对比

适合：混乱/有序，手动/自动，分散/收拢，焦虑/稳定。

画法：左混乱（碎纸片散落、线条缠绕），右稳定（整齐归档、贴好标签），中间橙色箭头。剪报从左到右移动，执行整理动作。

### 角色状态

适合：用户痛点、创作者状态、工具太多、信息焦虑、卡住到跑起来。

画法：2-4 个小状态，每个状态一个短标注，像档案袋上的分类标签。剪报在每个状态有不同的姿态——卡住时蹲着、跑起来时大步走。

### 概念隐喻

适合：内容工厂、信息仓库、脑内黑盒、工作流机器、自动日报。

画法：一个大的怪物件或机器（由旧零件剪报拼成），少量输入，一个输出。剪报在机器里执行某个关键动作。要有记忆点——这台机器看起来荒诞但逻辑成立。

### 方法分层

适合：方法论框架、系统层级、能力栈、内容系统分层。

画法：一层层像档案盒叠放或抽屉嵌套，不要正式金字塔；剪报在旁边搬砖或搭建——比如扛着纸盒往上叠、用胶带固定层级。

### 地图路线

适合：从想法到上线、用户路径、内容承接路径、学习路线。

画法：一条弯曲路径（像旧地图上的手绘路线），少量节点，剪报牵线或走路——比如拉着一条绳穿过各个标记点、在地图上盖章做记号。

### 小漫画分镜

适合：失败到成功、真实过程、吐槽、使用前后变化。

画法：2-4 个小场景，每格只表达一个动作。像旧连环画的分镜，剪报在每格执行不同的核心动作。

## 原创隐喻生成法

每次都从当前文章重新发明隐喻，不能照搬旧图。

### 三步

1. 把抽象概念换成一个物理动作：卡住、漏掉、变重、分拣、沉淀、发酵、开门、折叠、拆包、回流。
2. 把系统结构换成一个低科技物件：坏掉的机器、纸箱、抽屉、水管、邮筒、怪表盘、秤、井、梯子、奇怪工位。
3. 让剪报承担动作：不是站旁边，而是卡在机器里、拉错线、守门、搬运、修补、称重、扶梯子、记录、把东西塞进某个怪装置。动作要服务核心意思，不要为了怪而怪。

### 可用物件池

- 纸箱、抽屉、旧机器、漏斗、秤、邮筒、门、井、梯子、水管、线团、闸门、转盘、黑盒、打孔器、压面机、晾衣绳、怪工位。
- 用时只选 1-2 个，不要堆满。物件本身也应该是剪报拼贴质感——从旧纸源剪下再拼合。

### 剪报动作池

- 拉、扛、塞、捞、压、称、缝、剪、拧、守、推、接、拆、标记、回收、盖章、穿线、打孔、搬运、分类。
- 动作要服务核心意思，不要为了怪而怪。

## 反复刻规则

不要默认打开或复刻 `assets/examples/`。这些图片只用于风格校准，例如线条密度、留白、颜色克制、剪报质感。

除非用户明确说"照这张 / 复刻这个构图 / 用这个案例改"，否则不要直接复用这些旧构图：

- 传送带两个断点
- 剪报在内容机器里拉判断杆
- 剪报变漏斗分拣流量/信任/转化
- 剪报切素材鱼
- 剪报牵承接路径
- 剪报拉三层信息源
- 三个剪报分别拿喇叭/搭桥/开门
- 剪报盖章话术工具箱
- 剪报举牌看常见坑路径

同类主题也要换新隐喻。例如"承接路径"不一定画路线，可以画剪报把内容尾巴接到门把手；"一鱼多吃"不一定画鱼，可以画剪报把一个纸团压成几种形状。
