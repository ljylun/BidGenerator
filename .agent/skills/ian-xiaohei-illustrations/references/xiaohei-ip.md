# 「大袖」IP

## 角色定义

「大袖」是深度文化、方法论、商业复盘或东方美学逻辑图的固定视觉 IP。

它不是古风装饰，不是贴纸，而是**用中国传统服饰的“垂坠、包裹、延伸”特性，在现代图表里拉扯框架、缝补逻辑的东方苦力**。

## 外形

* **极简几何结构**：由两到三个极为流畅、边缘锐利（或极具毛笔顿挫感）的色块组成。最核心的视觉符号是**两只夸张、宽大、垂坠的交领大袖**。
* **无面人**：没有五官，没有发型。头部只是一个简单的留白圆圈，或者是一个极简的斗笠剪影。
* **色彩克制**：整体采用高纯度的中国传统色单色（如：朱砂红、曜石黑、或石绿），与现代黑白图表形成强烈视觉反差。
* **线条质感**：衣服的轮廓具有强烈的东方白描或书法飞白质感，有风骨，不圆润。

## 性格

* **大智若愚，道法自然**：看似飘逸出尘，实则在图表里干着最接地气的苦力活。
* **以柔克刚**：不靠蛮力，擅长用衣服的物理特性（甩、卷、抛、藏）去解决复杂的架构问题。
* **清冷、幽默、不卖萌**：有一种“无能为力但依然在维持秩序”的荒诞感。

## 常见职责

让「大袖」用它的服饰结构承担核心动作：

* **长袖善舞（信息连接）**：两只大袖子被无限拉长，像两条丝带一样，跨越半个屏幕把两个八杆子打不着的“异资产模块”强行系在一起。
* **袖里乾坤（隐蔽容纳）**：一只巨大的袖口张开，像黑洞一样，正在把一堆乱七八糟的“底层数据/历史包袱”往袖子里扫。
* **顺水推舟（路径引导）**：身体顺时针旋转，宽大的裙摆和袖子甩出一个完美的太极弧线，把原本直角生硬的“用户转化路径”导向下一个环节。
* **垂衣拱手（稳固承重）**：双袖下垂，双手作揖。巨大的衣袖如同两根稳固的中国古建筑立柱，死死撑住上方沉重的“核心KPI方框”。
* **掩面反思（断点卡顿）**：用一只大袖子捂住大半个身子（表示“非公开/测试中”），只露出一只脚卡在流程图的断点里。
* **披荆斩棘（边界划分）**：衣襟化作一把锐利的裁纸刀，正在把一个杂乱的“业务混沌体”一刀劈成“左阳右阴”两个清晰的板块。

## 禁止

* **拒绝过度装饰**：绝对不要画出复杂的汉服绣花、配饰（如玉佩、发簪、流苏）、褶皱。
* **拒绝动漫化**：不要画成大眼睛的Q版古风娃娃，不要有任何二次元或萌系表情。
* **拒绝当背景板**：不要让它只是穿着汉服抱剑靠在方框旁边看，它必须用它的袖子或衣襟参与构图。
* **拒绝廉价国潮**：不要堆砌祥云、灯笼、折扇等符号，它本身就是唯一的中国元素。

## 判断标准

如果去掉「大袖」，画面里那些原本飘逸、流动的**中式线条逻辑**（如弧形连线、留白过渡）瞬间塌陷，变成了一张毫无美感的普通表格，说明「大袖」成功融入了结构。
