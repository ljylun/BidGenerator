# 墨丁 IP

## 角色定义

墨丁是中国传统文化知识系统里的一个底层执行者。

它不是书童，不是仙童，不是吉祥物，而是在宣纸、古籍、书法、国画、篆刻、建筑、礼仪这套庞大文化体系里，负责某个具体、微小、甚至有点笨拙的物理操作的角色。它存在于文化传承的“后台”，做那些被人忽略但系统离不开的杂活。

## 外形

- 身体是一块不规则的**墨块**或**墨迹**，有手工研墨留下的边缘痕迹，不圆滑，不规整。
- 眼睛是两个极小的白色圆点，有时像宣纸上没被墨覆盖的两个针孔。
- 肢体是几笔**枯笔飞白**的线条——细、干涩、有断续，像是用快没墨的毛笔快速拖出来的。
- 身体形状可以变体为：
  - 一块用了一半的松烟墨锭
  - 砚台里的一小滩墨迹
  - 拓片上的一团墨影
  - 古籍蛀洞形状的黑块
  - 折扇折叠处的阴影
  - 印章的侧面剪影
- 轮廓绝对不规整，有手研墨块特有的微涩边缘感。
- 表情空、静、钝、认真。像一方静置在案头的墨，突然被赋予了干活的意识。

## 性格

- 很认真，但做事的方法有点笨拙和迂回。
- 像一个在旧书铺后堂干活的小伙计，不问为什么，只管做好手头的事。
- 沉默寡言，冷幽默藏在动作里。
- 尊重“规矩”，但执行起来会意外地荒诞。
- 不是在“表演”传统文化，它就是文化运转中一颗认真的螺丝钉。

## 常见职责

让墨丁承担与传统文化相关但被荒诞化的核心动作：

- **研墨**：但不是研墨写字，而是磨掉一段错误的历史记录。
- **托裱**：把断裂的信息碎片用浆糊重新拼接。
- **拓印**：从一块残碑上拓下即将消失的数据。
- **校对**：用朱笔圈出古籍中的逻辑漏洞。
- **盖印**：用一方大得过分的收藏印，压住一条想逃跑的“不实信息”。
- **分拣**：在字纸篓里回收可以重新使用的典故。
- **修补**：用纸浆填补“文化断层”的裂缝。
- **打捞**：从一缸洗笔水里捞起还没化完的关键词。
- **引线**：牵一条装订线，穿过散落的书页，把它们重新串起来。

## 禁止

- 不要把墨丁画成可爱的水墨动画角色或胖墩墩的书童。
- 不要给它画汉服、头巾、发髻等明确的古代装扮。
- 不要让墨丁成为“中国风”的装饰符号——它必须是工作的主体。
- 不要把画面画成精致的新中式插画或商业国潮海报。
- 不要让它只是站在文房四宝旁边——它自己就是那个正在干活的“墨”。
- 不要出现龙、凤、祥云、灯笼等堆砌的中国符号，克制到只用必需物件。

## 判断标准

如果去掉墨丁，画面仍然是一张完整的“传统文化示意图”，那它就是装饰——要重写，让它成为那个让系统运转下去的荒诞操作员。
