### 阶段3：文件整理与重命名

**目标**: 统一文件命名规范，确保目录结构清晰

**任务**:
1. 创建文件整理脚本 `organize_files.py`
2. 按以下命名规范重命名文件：
   - 格式: `[财年]_[报告类型]_[日期].[扩展名]`
   - 示例: `FY2024_10-K_2024-09-28.htm`
3. 将子文件夹中的文件移动到对应分类目录
4. 处理Other目录中的文件，按文件类型归类

**文件命名映射规则**:
| 原文件模式 | 新文件命名 |
|------------|-----------|
| `YYYYMMDD_aapl-YYYYMMDD.htm` (10-K) | `FYXXXX_10-K_YYYY-MM-DD.htm` |
| `YYYYMMDD_aapl-YYYYMMDD.htm` (10-Q) | `FYXXXX_10-Q_Q[1-4]_YYYY-MM-DD.htm` |
| `YYYYMMDD_aapl-YYYYMMDD.htm` (8-K) | `FYXXXX_8-K_YYYY-MM-DD.htm` |
| `YYYYMMDD_*def14a*.htm` | `FYXXXX_DEF-14A_YYYY-MM-DD.htm` |
| `YYYYMMDD_xslF345X0[3-5]/` (Form 4) | 保留原目录结构 |
| `YYYYMMDD_xsl144X01/` | 保留原目录结构 |

### 阶段4：生成文件清单CSV

**目标**: 创建完整的文件清单，便于追溯和核对

**输出文件**: `Apple_Financial_Reports/file_inventory.csv`

**CSV字段**:
| 字段 | 说明 |
|------|------|
| filename | 文件名 |
| file_type | 文件类型 (10-K, 10-Q, 8-K, DEF-14A, Other) |
| fiscal_year | 财年 |
| filing_date | 发布日期 |
| file_size | 文件大小 (bytes) |
| file_extension | 文件扩展名 |
| download_url | 下载来源URL |
| local_path | 本地存储路径 |
| md5_hash | MD5校验和 |
| sha256_hash | SHA256校验和 |

**实现脚本**: `generate_inventory.py`

### 阶段5：文件校验

**目标**: 确保所有文件完整可用

**校验项目**:
1. ✅ 文件存在性检查
2. ✅ 文件大小非零检查
3. ✅ HTML格式文件可打开性验证（检查是否为有效HTML）
4. ✅ XML格式文件可解析性验证
5. ✅ 文件大小合理性检查（与下载日志对比）
