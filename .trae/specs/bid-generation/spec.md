# 湖南省政务服务大厅信息化项目运维 标书生成 Spec

## Why
用户需要基于招标文件（招标正文.doc）生成一份完整的投标文件，覆盖商务标、技术标、报价标三大模块，确保内容完整响应招标要求，格式规范，逻辑清晰，能够通过评审。

## What Changes
- 基于已解读的招标文件内容，生成完整的投标文件
- 文件包括：资格证明文件、商务文件、技术文件三大组成部分
- 严格按照招标文件第七章"投标文件的组成"逐项编制
- 确保所有★条款（实质性要求）完全响应，无偏离
- 报价不超过最高限价1489502.38元
- 完成废标风险自查

## Impact
- 输出位置：`h:\DEV\MyProjects\BidGenerator\doc\` 目录下
- 输出格式：Markdown文件（可转换为Word/PDF）
- 覆盖全部评审维度：技术部分(55%)、商务部分(35%)、价格部分(10%)

### 评审标准（综合评分法）

#### 评分权重
| 部分 | 权重 |
|------|------|
| 技术部分 | 0.55 (55%) |
| 商务部分 | 0.35 (35%) |
| 价格部分 | 0.10 (10%) |

#### 技术部分评分（满分100分）
| 评审因素 | 分值 | 计分标准 |
|----------|------|----------|
| 需求理解 | 12分 | 包含大厅应用系统现状、网络现状、与省一体化平台关系、与省云平台关系分析 |
| 技术方案 | 18分 | 包含"湘易办"对接运维、"一网通办"平台对接运维描述 + 承诺函 |
| 硬件维护方案 | 24分 | 覆盖窗口设备/桌面终端、智能终端、显示屏、叫号广播、网络设备、会议系统、空调、监控 |
| 软件运维方案 | 18分 | 覆盖取号叫号、预约取号、候时查询、自助办理、信息发布、数据统计分析 |
| 故障处理流程 | 8分 | 热线服务、上门服务、现场服务、突发事件应急处理流程图 |
| 服务保障 | 20分 | 运维人员组织、质量保障、现场服务、远程支持、应急响应 |

#### 商务部分评分（满分100分）
| 评审因素 | 分值 | 计分标准 |
|----------|------|----------|
| 综合实力一 | 15分 | ISO 9001(5分)、ISO 27001(5分)、ISO 22301(5分) |
| 综合实力二 | 15分 | 系统架构设计师(5分)、系统规划与管理师(5分)、ITSS服务证书(5分) + 社保证明 |
| 综合实力三 | 20分 | CS4及以上(20分)、CS3(15分)、CS2(10分)、CS1(5分) |
| 综合实力四 | 30分 | 信息安全服务资质一级(10分/项)、二级(5分/项)，最多30分 |
| 项目案例 | 20分 | 2021年1月1日至今政务服务平台/大厅类似项目，每个4分，最高20分 |

#### 价格部分评分（满分100分）
- 低价优先法：评标基准价 = 最低投标报价
- 价格得分 = (评标基准价 / 投标报价) × 价格权值 × 100
- 价格权值 = 0.10

### 政府采购政策优惠
- 小微企业：价格部分扣除10%
- 监狱企业/残疾人福利性单位：价格部分扣除10%
- 节能产品：技术+5%、价格+5%
- 环境标志产品：技术+5%、价格+5%

## ADDED Requirements

### Requirement: 完整标书生成
系统 SHALL 生成包含以下全部内容的投标文件。

#### Scenario: 生成完整标书
- **WHEN** 用户提供招标文件路径并请求生成标书
- **THEN** 系统生成包含资格证明文件、商务文件、技术文件的完整投标文件

### Requirement: 评审维度全覆盖
系统 SHALL 确保技术部分6个评分项、商务部分5个评分项全部覆盖。

#### Scenario: 技术部分评审响应
- **WHEN** 生成技术方案章节
- **THEN** 包含需求理解(12分)、技术方案(18分+承诺函)、硬件维护方案(24分)、软件运维方案(18分)、故障处理流程(8分)、服务保障(20分)

#### Scenario: 商务部分评审响应
- **WHEN** 生成商务章节
- **THEN** 包含ISO证书响应、人员资质响应、CS等级证书响应、信息安全服务资质响应、项目案例列表

### Requirement: 报价合规性
系统 SHALL 确保投标报价不超过最高限价1489502.38元。

#### Scenario: 报价校验
- **WHEN** 生成报价表
- **THEN** 总价 ≤ 1489502.38元，大小写金额一致，分项报价汇总与总价一致

### Requirement: 投标文件格式规范
系统 SHALL 按照招标文件第七章规定的投标文件组成顺序编制。

#### Scenario: 格式检查
- **WHEN** 生成投标文件
- **THEN** 按以下顺序：资格证明文件封面 → 资格证明第一部分 → 资格证明第二部分(附件1-5) → 商务文件封面 → 投标函 → 开标一览表 → 分项报价明细表 → 商务要求响应 → 商务偏离表 → 政策优惠证明 → 综合实力(一至四) → 项目案例 → 技术文件封面 → 技术采购需求响应 → 技术偏离表 → 代理服务费承诺书 → 需求理解 → 技术方案 → 硬件维护方案 → 软件运维方案 → 故障处理流程 → 服务保障

### Requirement: 废标风险自查
系统 SHALL 对标书进行32项废标红线自查。

#### Scenario: 废标自查
- **WHEN** 标书初稿完成后
- **THEN** 逐项检查：投标范围完整性、报价一致性、★条款响应情况、签章有效性、投标有效期等
