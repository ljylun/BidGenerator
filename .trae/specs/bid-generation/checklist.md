# Checklist

## 商务标检查项
- [ ] 资格证明文件封面格式正确（项目名称、编号、投标人名称填写完整）
- [ ] 投标人基本情况表填写完整（名称、地址、注册信息、近三年营业额）
- [ ] 投标人资格声明内容完整（涵盖《政府采购法》第二十二条全部6项）
- [ ] 授权委托书格式正确（法定代表人签字、授权范围明确）
- [ ] 投标函内容完整（报价确认、有效期承诺、签章齐全）
- [ ] 开标一览表填写完整（大小写金额一致）
- [ ] 分项报价明细表逐项填写（无缺项漏项，无"免费"或"零"报价）
- [ ] 商务偏离表如实填写（无偏离项需注明"无偏离"）
- [ ] 综合实力响应覆盖全部评分项（ISO证书、人员资质、CS等级、信息安全资质）
- [ ] 项目案例列表完整（2021年1月1日以来的政务类项目，附合同复印件说明）
- [ ] 代理服务费承诺书格式正确（承诺支付金额不超过15712元）
- [ ] 免交投标保证金承诺书已提供

## 技术标检查项
- [ ] 需求理解章节覆盖4个分析维度（应用系统现状、网络现状、与一体化平台关系、与云平台关系）
- [ ] 技术方案包含"湘易办"超级服务端对接运维描述
- [ ] 技术方案包含"一网通办"平台对接运维描述
- [ ] 技术方案包含承诺函（第三方费用承担承诺）
- [ ] 硬件维护方案覆盖8类设备（窗口设备/桌面终端、智能终端、显示屏、叫号广播、网络设备、会议系统、空调、监控）
- [ ] 软件运维方案覆盖6大功能（取号叫号、预约取号、候时查询、自助办理、信息发布、数据分析）
- [ ] 故障处理流程包含4类流程图（热线服务、上门服务、现场服务、突发事件应急处理）
- [ ] 服务保障方案覆盖5个方面（人员组织、质量保障、现场服务、远程支持、应急响应）
- [ ] 技术偏离表如实填写（无偏离项需注明"无偏离"）

## 报价标检查项
- [ ] 投标总价不超过最高限价1489502.38元
- [ ] 大写金额与小写金额一致
- [ ] 分项报价汇总等于总价
- [ ] 报价包含全部服务内容（无缺项）
- [ ] 报价大小写同步生成

## 合规性检查项
- [ ] 所有★条款（实质性要求）完全响应
- [ ] 投标有效期不少于90日历日
- [ ] 不接受联合体投标（本标书为独立投标）
- [ ] 不允许分包（本标书无分包计划）
- [ ] 投标范围覆盖完整包（包01全部内容）
- [ ] 无重大违法记录声明
- [ ] 信用记录自查（信用中国、中国政府采购网无不良记录）
- [ ] 文件签章齐全（单位电子签章、法定代表人/授权人电子签章）
- [ ] 投标文件按招标文件第七章规定顺序编制
