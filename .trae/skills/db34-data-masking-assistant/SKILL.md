# DB34 数据脱敏助手技能

本技能旨在帮助用户理解并应用《DB34/T 政务数据 第2部分：脱敏技术规范》进行数据脱敏工作。它能够提供规范咨询、脱敏方案建议、模拟脱敏处理以及生成审计相关文档。

## 核心功能

### 1. 合规咨询

提供关于 DB34 脱敏规范的定义、基本要求、技术分类和流程等方面的详细解答，确保用户操作符合标准要求。

### 2. 脱敏方案设计

根据用户提供的数据类型、敏感字段以及具体的应用场景（如开发测试、数据分析、数据共享、数据开放等），智能推荐符合规范的脱敏技术和脱敏形态（静态脱敏或动态脱敏）。

### 3. 模拟脱敏处理

对用户提供的结构化数据样本（如 CSV、JSON 文件）执行模拟脱敏操作，直观展示不同脱敏技术的效果，并提供字段级的脱敏说明。

### 4. 审计文档生成

根据规范附录 B 的要求，自动生成脱敏申请表草案和风险检查清单模板，辅助用户完成合规性审计工作。

## 如何使用

您可以通过以下方式激活本技能：

*   `/db34-masking`
*   `/data-masking-audit`
*   提及“数据脱敏规范”或“DB34 脱敏”等关键词

**示例用法：**

*   `/db34-masking 什么是数据脱敏？`
*   `/db34-masking 我有一个包含用户手机号和身份证号的数据库，用于开发测试，请推荐脱敏方案。`
*   `/db34-masking 对附件中的 sales_data.csv 文件进行手机号和身份证号脱敏。`

## 规范性引用

本技能的核心逻辑和建议均严格遵循以下规范：

*   **《DB34/T 政务数据 第2部分：脱敏技术规范》**
*   GB/T 25069 信息安全技术 术语
*   GB/T 35273 信息安全技术 个人信息安全规范
*   GB/T 37964 信息安全技术 个人信息去标识化指南
*   GB/T 37988 信息安全技术 数据安全能力成熟度模型
*   GB/T 39477 信息安全技术 政务信息共享 数据安全技术要求
