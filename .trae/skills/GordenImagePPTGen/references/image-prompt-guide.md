# 功能 A：图片型 PPT 提示词体系

目标：用 GPT Image 生成**极其复杂、豪华、排版绚丽、信息密度极高**的 PPT 图片；同时具备切换到简洁/卡通/水墨等任意风格的灵活度。**默认走"高密度豪华信息图"**，除非用户明确要别的风格。

> 🔴 **出图铁律：成品必须是"含全部真实文字"的完整幻灯片，绝不能是占位符/空模板/无文字的图。**
> - 每页**真正用于出图的提示词 = §2 模板**，其中【页面文字】必须写满**全部真实文字(verbatim)**：主标题、小节编号、导语、每个模块的标题/要点/重点数字、底部横幅，一字不差。
> - §7 的 `outline.json` 里 `visual_generation_prompt` **只是"画面"半成品（故意不含文字）**，**绝不能拿它单独去出图**——必须把它和【页面文字】合并进 §2 模板再出图。
> - 生成出来的图要能直接读到所有文字。若出现 lorem/占位框/无字卡片，视为**失败**，改提示词重出（功能 A 产出的就是"原始图片 PPT 成品"，不是给功能 B 用的空模板）。

## 0. 内容优先（最重要 · 复杂排版的前提）

**"排版太简单"几乎都是因为内容太薄**——只给一页 4~5 个孤立数据点，再好的网格也撑不满，看起来就空。所以**先备内容、再出图**：

1. **先看参考图**（`参考图/`，§1.6）确定本页要对标的密度与结构。
2. **为每页备齐"够撑满复杂排版"的内容**，再写提示词。一张内容页的内容量基线（对标参考图）：
   - 1 句**导语**（含 2~3 个高亮关键词）；
   - **3~4 个并列模块/列**（而非 1~2 个）；
   - **每个模块内**：模块标题 + **2~3 条要点** + **1 个特大号指标数字（带单位/说明）** + 1 个标签/进度条/百分比；
   - 1 条**底部总结横幅**。
   - 即：一页通常 ≥ 4 模块 × (标题+2~3 要点+1 指标) ≈ 20+ 个文字信息点。
3. 内容不足时，**先把内容做厚**（补真实的子要点、指标、分类维度），而不是靠放大字号填白。**绝不编造数据**：可补的是结构化拆解（如把"上市"拆成 时间/募资额/意义），不是虚构数值。
4. 把这份内容写进 `prompts/NN-*.md` 的【页面文字】（verbatim），再出图。**内容厚了，复杂排版自然成立。**

## 1. 设计人格与默认基调

你是顶级商业信息图设计师（麦肯锡/BCG 级 + 杂志级视觉）。默认每页都要：

- 高度结构化、模块化的**网格布局**；带微妙投影的**卡片容器**、连接线、指示箭头、现代扁平商务图标。
- 强调"信息量巨大""高密度数据展示"；**重点数字特大号加粗**。
- 一页一个核心信息，但围绕它堆叠丰富的子模块、标注、图例，做到"满而不乱"。
- 干净的无衬线字体（微软雅黑/思源黑体风格）。

## 1.5 复杂度强制清单（默认每张内容页都要尽量做满）

默认输出要"信息密度极高、层次丰富"。**简单 = 不合格**。每张内容页至少包含下列 6 项中的 4 项以上（封面/结尾可少）：

1. **小节标题区**：左侧竖条/编号（如 `01` / `1.1`）+ 标题 + 标题下方一条**短强调分割线**（细横线）。
2. **一句导语**：标题下一行的引导句，句中**关键词用强调色高亮**。
3. **中心高阶图表 或 多列模块**：莫比乌斯环 / 同心圆 / 多边形闭环 / 鱼骨 / 仪表盘 / Hub-Spoke / 金字塔架构（见第 4 节）；或 3–5 列模块化卡片。
4. **模块内分层**：每个卡片/模块内再分小层——子标签横幅（如「成果描述」「数据支撑」「占总营收」）+ 要点列表（带小图标项目符号）+ **特大号重点数字/百分比**。
5. **微件**：标签药丸（小圆角标签，如「下沉市场」「数据驱动」）、进度条 / 开关滑块（带 %）、连接线与指示箭头、环上节点编号。
6. **底部总结横幅**：整页底部一条通栏色带，放一句核心结论（字距加大）。

> 参考"满而不乱"：信息多但有清晰的网格、对齐、留白与层级。重点数字最大、标题次之、正文最小，强调色只点睛不铺满。

## 1.6 排版参考图库（只学排版，不抄配色）

技能自带 `参考图/` 文件夹（`leader_love / red_grey_project / scholar_green / tech_prize / work_result` 等子集，每个含 ref1..N.png），是高密度复杂排版的范例。用法：

- **优化提示词**：动笔前浏览与本页结构最接近的 1–2 张参考图，把它的**布局骨架**（分区、列数、中心图表形式、子标签层级、底部横幅、callout 位置）吸收进提示词的【版式结构】。
- **可作生图参考图**：出图时可把选中的参考图作为 reference 传入后端（Codex 见 runtime-notes），并在提示词中明确：**只参考它的排版/构图，不要使用它的配色**，配色一律用本页【整体风格】里指定的颜色。
- 严禁直接照搬参考图的文字、颜色、品牌元素。

## 1.7 豪华信息图设计准则（教科书级复杂度 · 每页不重样）

你不是在"总结要点"，而是在**设计信息图谱**。每页都要对标**顶级互联网大厂的技术架构图 / 顶级咨询公司的全景图**那种复杂度与华丽度——**拒绝简单 bullet points**。落地三条硬规则：

1. **每页一个"复杂视觉框架"，且全篇不重复**（最重要的丰富度来源）。从 §4 目录里为每页选一个**不同**的高阶结构：房子型架构、莫比乌斯环、Bento 便当盒看板、同心圆雷达扫描、多层 3D 架构、3D 折叠彩带/阶梯、鱼骨图、DNA 双螺旋、漏斗、Hub-Spoke、金字塔… 一套 PPT 里**不能出现两页相同的布局骨架**。
2. **全篇统一配色**：整套 PPT 用**同一套配色方案**。用户给了参考图 → 提取参考图配色；没给 → 按主题定一套（主色1+辅色1~2+强调色1+中性背景），并写死 hex，每页复用。**绝不逐页换色**。
3. **容器化 / 模块化 / 流线性 + 华丽质感**：内容都装进有层次的容器（卡片/面板/环/层），模块之间有连接线、箭头、流向；加入**景深、渐变、辉光、玻璃/金属质感、定向光照**做出"高级豪华"的立体感（而非扁平贴图）。重点数字特大号发光，关键路径有指向。

> "豪华"= 复杂的视觉逻辑结构 + 统一高级配色 + 立体光影质感 + 极高信息密度。不是堆装饰，是**有逻辑的繁复**。

> ⚠️ **豪华 ≠ 浮夸（清晰永远第一）**：过度的辉光、3D 戏剧化光效、浓重金属/玻璃质感会让画面"花哨、难读"。**默认走"清晰科技"基调**——浅底 + 细科技网格/电路线 + **扁平**模块卡（细边框、克制投影）+ 细线连接 + 克制的强调色 + 高信息密度；复杂度体现在**框架结构与信息量**，而非光效堆叠。要质感时也以"清晰可读"为前提，宁可扁平干净，不要炫技糊脸。

## 1.8 高密度成品配方（实战清单 · 直接照搬组合）

把"复杂/豪华/高密度"落到**具体可画的组件**上。每张内容页从下表挑 **3~4 类组件**拼满版面（不同页用不同主框架，§1.7 规则1）：

| 组件 | 怎么画 | 放哪 |
|---|---|---|
| KPI 芯片带 | 4~5 枚白底细边小卡，每枚 特大号强调色数字 + 灰色小字说明（可带迷你图标） | 封面主标下方 / 内容页顶部一行 |
| 里程碑缎带 | 贯穿底部的时间轴，6~7 个渐变节点圆点 + 竖分隔，每点 年份(强调色)+事件小字 | 封面 / 章节页底部 |
| 嵌入式 mini 图表 | 折线/柱状/阶梯小图，**带坐标轴 + 每个数据点的数值标签**（如 营运里程 2008→2023） | 内容页一角 / 看板面板 |
| 分层架构带 | 3~5 条水平长条层，每层 左端层名(中英) + 4~5 个等宽模块卡(图标+名) + 层间箭头 | "技术体系 / 端到端"页主体 |
| 侧栏 KPI rail | 窄竖条，3~4 枚 强调数字 + 说明（可含一个迷你饼/环） | 架构 / 看板页右侧 |
| 地图 + 定位连线 | 淡色地图轮廓 + 若干强调色定位点 + 连向中心的虚线 + 右侧项目清单(图标+文字) | "布局 / 出海 / 网络"页 |
| 阶段大卡时间轴 | 横向主轴 + 4 节点，每节点挂一张卡(标题条 + 年份 + 4 要点 + 大指标 + 说明) | "历程 / 路线图"页主体 |
| 底部主张横幅 | 通栏强调色细横幅，居中白色粗体一句话 | 收尾 / 章节页底部 |

两条让画面"高级"的稳妥手法（不浮夸）：
- **主题化淡背景底纹**：与主题相关的极淡线条底图（如 路网地图 / 流线列车剪影 / 数字孪生线框 / 城市天际线），压到很淡当背景，立刻有"大片感"又不抢文字。
- **统一规整网格**：所有模块卡等宽等高、严格对齐；强调色只点睛（数字 / 关键词 / 横幅），其余藏青 + 灰 + 白。

> 🔑 **逐区域写死提示词**（本节最关键）：把页面切成【页眉(编号+标题+分割线+导语)】【主体(逐模块列全部 verbatim 文字)】【侧栏/图表(列全部数值)】【底部横幅】，**每个区域的每条文字都照排、每个模块都列全**——区域写得越具体、模块列得越全，出图越复杂越准。一张合格内容页通常 ≥ 25 个文字信息点。范例见 `GordenSuperPPTSkill` 跑出的中国高铁 5 页（封面/时间轴/分层架构/数据看板/展望）。

## 4. 高阶图表形式目录（结构 → 形式 映射）

按用户内容的**结构**选形式（结构优先）：

| 内容结构 | 推荐图表形式 |
|---|---|
| 顶层战略 / 支撑体系（愿景+支柱+地基） | **房子型架构图**（屋顶=愿景，立柱=支柱，地基=底座） |
| 统一策略 / 生态闭环 / 无尽价值循环 | 3D 莫比乌斯环、无限循环符号（带立体质感与流光） |
| N 个步骤的循环（如"8 大策略循环"） | N 节点莫比乌斯环 / 多边形（五/六边形）闭环，中心放核心图标 |
| 多要素并列总览（不规则主次） | **Bento Box 便当盒看板**（大小不一的网格单元，主单元更大） |
| 多维能力 / 扫描评估 | **同心圆雷达扫描图**（雷达环 + 扇区 + 节点） |
| 分层体系 / 技术栈 / 端到端架构 | **多层 3D 架构图**（堆叠的 3 ~ 5 个立体层，层间有数据流） |
| 演化 / 双链协同进化 | **DNA 双螺旋进化链**（两条螺旋 + 横档节点） |
| 协同效应 / 双轮驱动 | 双圆交织（Venn）、两环咬合 |
| 多维发力 / 多引擎 | 三环重叠、多重同心圆，环上带节点标注 |
| 单一指标 / 完成度 / 占比 | 半圆仪表盘、环形进度 |
| 问题诊断 / 归因 | 鱼骨图（Ishikawa） |
| 筛选 / 取舍 / 转化漏斗 | 漏斗图 / 奥卡姆剃刀漏斗（层层过滤） |
| 现状评估 | SWOT 矩阵、四象限 |
| 端到端流程融合 | 全栈流融合（Full-Stack Flow，泳道 + 汇流） |
| 线性增长 / 阶段递进 | 3D 折叠彩带箭头、3D 阶梯步骤图 |
| 时间线 / 路线图 | 锯齿状时间轴、蜿蜒里程碑路径、3D 折叠时间带 |
| KPI 总览 | 全景 Dashboard（多卡片 + 迷你图 + 雷达 + 柱） |
| 层级 / 优先级 | 金字塔、堆叠层 |
| 中心辐射 / 概念地图 | Hub-Spoke 放射 |

(e) 鼓励发挥其它复杂信息图形式。**同一套 PPT 内每页选不同的形式（§1.7 规则1）；不要在图上标注你用的是什么形式的名称。**

## 5. 风格库

### 默认风格：豪华高密度信息图（luxury-dense）
深色或品牌色底（藏青/墨绿/酒红/科技深蓝）+ 金属/玻璃质感卡片 + 霓虹或金色强调 + 大量数据模块；或浅色高级杂志风（纯白/浅灰底 + 强对比标题 + 彩色强调块）。信息密度高、层级丰富、装饰精致。

### 常用风格：科技商务 / 浅色信息图（tech-business，对标 `参考图/`）
**浅色背景**（白 / 极浅冷灰 #F4F6F9）+ 右上角极淡科技网格/几何光线纹理；主色企业红 + 深藏青 + 钢灰 + 白，关键词红色高亮。
模块为**白色卡片（细投影、圆角）+ 彩色标题条（红/藏青交替）**，要点前带小号徽标图标，指标用特大号红字，配标签药丸/进度条/百分比，底部红色满幅总结横幅。
顶部统一「红色小节编号 + 藏青粗体标题 + 标题下红色短分割线 + 右上导语(关键词高亮)」。干净、专业、信息密度高——这正是 `参考图/red_grey_project · work_result · tech_prize` 的气质，是"科技商务风"的首选。

### 备选风格（仅当用户明确要求时切换）

| 关键词 | 风格指引 |
|---|---|
| 简洁 / 极简 / 商务干净 | 大量留白，单一强调色 + 灰阶，1 个核心元素，克制装饰 |
| 卡通 / 可爱 / 童趣 | 圆润形状、明快撞色、手绘插画图标、活泼字体 |
| 水墨 / 国风 / 中式 | 宣纸纹理、水墨晕染、留白意境、印章红点、衬线/楷体气质 |
| 手绘 / sketch | 手绘线条、便签/黑板质感、不规则边框 |
| 科技 / 蓝图 | 网格底纹、电路/蓝图线条、冷色调、技术感标注 |
| 杂志 / 编辑 | 强对比大标题、分栏、引用框、Wired/The Verge 气质 |
| 暗黑 / 大气 | 深色全幅、电影感光影、强戏剧性 |

切换风格时，把对应基调写进基础模板的【整体风格】，并保持全套幻灯片视觉语言一致（同一套配色、图标风格、网格、字体层级）。

## 6. 配色与字体

- **配色**：每页主色 1 + 辅色 1–2 + 强调色 1，全套统一；标题/正文对比充足。**默认避免大面积纯绿**（功能 B 默认绿幕抠图，绿色会冲突；若必须用绿，功能 B 改非绿底色）。
- **字体**：中文用微软雅黑/思源黑体风格无衬线（国风可用楷/宋）；英文用几何无衬线；标题加粗、字号为正文 2–3 倍；重点数字最大。

## 7. 大纲格式（A2 产出 `outline.json` · 逐页结构化设计）

把每页当成一次"信息图设计"来写，**先解构内容、再为每页指派一个不重复的复杂视觉框架**。默认 **11–20 页**（用户指定则从用户）。统一一套配色（有参考图就提取参考图配色）。逐页输出下面这个 JSON 结构：

```json
[
  {
    "slide_number": 1,
    "title": "本页主标题（叙事化，非'关键数据'这类干标题）",
    "sub_title": "副标题/定位说明",
    "core_logic": "一句话说明本页要解决的问题或展示的逻辑关系（如：从混乱到有序的过滤、多方协作的生态循环）。",
    "visual_framework": "本页选用的复杂框架名（§4，全篇不重复，如 '房子型架构图' / 'Bento 便当盒看板' / '多层3D架构' / '莫比乌斯环'）",
    "visual_generation_prompt": "纯画面描述：背景、主体框架的结构与立体形态、光照方向、数据如何呈现成视觉形态、质感（玻璃/金属/辉光/景深）。只描述画面，不写文字排版。统一配色写死 hex。",
    "detailed_content_paragraphs": [
      "第一段长文：现状分析 + 痛点挖掘 + 具体数据支撑（全用用户真实数据，禁编造）",
      "第二段长文：解决方案 + 执行步骤(Step1/2/3) + 涉及部门/角色",
      "第三段长文：预期回报 / ROI / 风险控制",
      "第四段长文：其它补充"
    ],
    "visual_assets": {
      "icons": ["建议图标语义1", "图标2", "图标3", "图标4"],
      "background_texture": "建议背景纹理（如 拓扑网格 / 代码矩阵 / 碳纤维 / 光晕）"
    }
  }
]
```

说明：
- `detailed_content_paragraphs` 是**本页的深度业务长文**（信息密度的来源）——它保证设计者手里有足够厚的内容去填满复杂框架。出图时把它**蒸馏**成页面上的标题/模块标题/要点/关键数字（逐字用真实数据），**不要把整段长文原样糊到图上**（会糊成乱码）。
- `visual_framework` **全篇不重复**；`visual_generation_prompt` 只描述画面、配色统一。
- ⚠️ **`visual_generation_prompt` 是半成品，禁止单独拿去出图**（它故意不含文字，单独出图会得到占位符/无字图）。必须把它与该页的【页面文字（verbatim 全部文字）】**合并进 §2 模板**，作为真正的出图提示词。
- 把这份 outline.json 落地成每页的【整体风格/版式结构/页面文字/图表形式/图标装饰】写进 `prompts/NN-*.md` 再出图（§2 模板）；**出的图必须含全部真实文字**（见文首出图铁律）。
- 标题叙事化（"用量 6 个月翻倍"而非"关键数据"）；避免"探索/深入/旅程/总而言之"等 AI 腔。

## 7.1 单页高稳定提示词范例（结构参考 · 经实测能稳定出"信息量大、排版复杂"的图）

下面这套**七段式结构**能让 GPT和Codex imagegen 稳定生成复杂 PPT 图，**照搬其结构与写法**（比例 / 标题 / 核心逻辑 / 视觉框架 / 视觉生成提示 / 详细内容 / 视觉元素+背景纹理），**风格、配色、文字一律按本页主题与用户要求来，不要照抄范例里的内容/配色**：

```text
生成一页 <16:9 / 3:2> 的图片，内容形式是 PPT 汇报图
标题
  <本页主标题 verbatim>
核心逻辑
  <一句话说明本页的逻辑关系：如"通过三维金字塔展示从物理交付到宏观价值的分层路径">
视觉框架
  <从 §4 选一个、全篇不重复：如 多层三维架构图 / 莫比乌斯环 / Bento 看板 / 同心圆雷达 …>
视觉生成提示
  <纯画面描述：主体框架的结构与立体形态、层级、光照方向、数据如何呈现成视觉形态、质感；
   并把要显示的关键标注/数据 verbatim 写进来，如"标注‘信众增长300%’、‘跨国贸易提升45%’">
详细内容
  第一段：<现状/成果 + 具体数据>
  第二段：<方案/分工/步骤>
  第三段：<成效/ROI/结论>
视觉元素（图标）
  <列图标语义：如 金色佛光 / 翻开的书卷 / 上升趋势线 / 大雁塔侧影>
背景纹理
  <如 圣洁光晕与流云纹 / 拓扑网格 / 蓝图线框>
```

> 范例（仅示范结构与"密度"写法，**不要套用其配色/题材**）：
> 标题「项目交付后的社会效益、人才产出与知识产权转化报告」；核心逻辑「通过三维金字塔展示从物理交付到宏观价值实现的分层路径」；视觉框架「多层三维架构图」；视觉生成提示「三层 3D 立体台阶：底层深灰‘物理交付层’、中层深红‘应用转化层’、顶层发光‘价值实现层’，台阶旁上升箭头标注‘信众增长300%’‘跨国贸易提升45%’」；详细内容三段（交付成果/团队晋升/社会 ROI）；图标「金色佛光、翻开的书卷、上升趋势线、大雁塔侧影」；背景「圣洁光晕与流云纹」。
>
> 落地提醒：①「详细内容」是**给设计者备的厚内容**，出图时**蒸馏**成标题/模块标题/要点/关键数字（verbatim 真实数据），别整段糊到图上；②「视觉生成提示」里要把**真正要显示的文字/数据**写明，确保成品含全部真实文字（呼应文首出图铁律）；③本范例等价于 §7 `outline.json` 的字段（title / core_logic / visual_framework / visual_generation_prompt / detailed_content_paragraphs / visual_assets），二者择一表达即可。

## 8. 出图执行要点（A4）

- 比例跟随用户（16:9 或 3:2），横版高分辨率。Codex 内置 `imagegen` 用提示词表达比例；CLI 后端用 `--size`。Cursor `GenerateImage` 原生 3:2（1536×1024）。具体见 [`runtime-notes.md`](runtime-notes.md) §5。
- 所有 `prompts/NN-*.md` 写齐后再批量开跑；并行批量（默认 4 张）；失败项只重试该项。
- 需要全套风格一致时：把同一【整体风格】块复制进每页；若后端支持参考图/会话，用首页或参考图锁定风格。
- 生成图移动到 `slides/NN-slide-{slug}.png`。
- 文字渲染：要求逐字照排用户文字；生僻词可在提示词里逐字拆开强调；中文标点。
